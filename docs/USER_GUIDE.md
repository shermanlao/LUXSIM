# 使用手冊 / User guide

LUXSIM 是照明設計輔助工具，不是標書認證計算。編輯器按鈕目前以英文為主，下文用這些英文名稱說明操作。

LUXSIM is a lighting design assist tool, not a tender-certified calculation. The names below match the English labels in the editor.

在 [Projects](/projects) 開啟專案後即可使用編輯器。本頁說明平面圖視野、畫房、編輯房間角點，直線排列的端點點選、圓形排列和多邊形排列、自動佈燈，DXF 物件吸附，以及計算後在平面與 3D 視圖切換等照度線與數值圖，包括近日補上、用家需要記住的快捷鍵。工具旁的「？」按鈕也有簡短提示。

Open a project from [Projects](/projects) to use the editor. This page explains plan view, room drawing, how to edit room corners, how to pick Line array endpoints, how to place a Circular or Polygon array, Automatic placement, DXF object snap, and how to switch Isolines and value labels on the plan and in the 3D view after Calculate, including the latest shortcuts. The **?** buttons next to tools also show short tips.

## 開啟專案 / Open a project

在 [Projects](/projects) 點選專案卡片，或使用 **New project**、**Open .lxm** 進入編輯器時，會出現載入對話框，顯示「Loading project…／正在載入專案…」。直接開啟專案網址時也會看到同一個對話框。載入完成、編輯器可以使用後，對話框會自行關閉；載入期間不能點背景關閉，也沒有關閉按鈕。若你最近在同一瀏覽器開啟過這個專案（或另外幾個常用專案），程式會先向伺服器確認專案沒有更新，確認後就從本機緩存打開，載入對話框會短很多；若專案已在其他分頁、裝置或由其他人儲存過較新版本，則會改從伺服器載入最新內容。建立新專案或開啟 .lxm 檔（舊的 .lux、.luxsim 或 .luxsim.json 檔同樣可以開啟）時，在進入編輯器之前也會顯示同一個對話框（「Creating project…／正在建立專案…」或「Opening project file…／正在開啟專案檔…」）。其他需要較長時間的工作同樣使用這個載入對話框，例如 **Calc room**／**Calc storey**／**Calc all**、匯出 **Full PDF report**、匯入圖則或光度檔、儲存大型專案、儲存 .lxm 專案檔、從圖則偵測燈具編號、按圖則燈碼佈燈、自動佈燈的預覽或套用、產生 LDT、從 DXF 建立房間、辨認房間（「Analysing rooms…／正在辨認房間…」）、套用圖則圖層，以及更新等照度線（「Updating isolines…／正在更新等照度線…」）。對話框會在工作進行期間顯示，完成並繪製結果後自行關閉；同樣不能點背景或關閉按鈕來取消。平移、縮放、選取、環繞旋轉 3D 視圖，或在屬性欄位輸入時，不會出現此對話框。官方專案檔副檔名為 .lxm；在 Documentation 模式按 **Save .lxm** 會開啟儲存路徑對話框（若瀏覽器支援），讓你選擇位置與檔名，再把專案名稱.lxm 與專案使用的圖則／底圖一併寫入。若取消對話框，不會另存檔案。若瀏覽器沒有此對話框，則改為下載到瀏覽器的下載資料夾。用 **Open .lxm** 在新帳戶或新工作區開啟時，會還原圖則、比例與位置，不必重新上傳。舊的 .lux、.luxsim 或 .luxsim.json 檔同樣可以開啟；沒有內嵌圖則的舊檔仍可開啟，房間、燈具、計算結果與光度檔會保留，但圖則不會被發明出來。

When you open a project from [Projects](/projects), after **New project** or **Open .lxm**, or by opening a project URL directly, a loading dialog shows *Loading project…* / *正在載入專案…*. It stays until the editor is ready to use, and cannot be dismissed by clicking the backdrop or a close button while the project is loading. If you recently opened this project in the same browser (or a few other projects you have been using), the app first checks with the server that nothing is newer, then reopens it from a local cache so the loading dialog is much shorter. If a newer save exists from another tab, device, or teammate, that current server version is loaded instead. Creating a new project or opening a .lxm file (older .lux, .luxsim and .luxsim.json files still open) shows the same dialog before the editor appears (*Creating project…* / *正在建立專案…*, or *Opening project file…* / *正在開啟專案檔…*). The same loading dialog also appears while other work that can take time is running, such as **Calc room** / **Calc storey** / **Calc all**, exporting the **Full PDF report**, importing a plan or photometry, saving a large project, saving a .lxm project file, detecting fixture codes from a plan, placing fixtures from plan codes, planning Automatic placement, generating an LDT, creating rooms from DXF, analysing rooms (*Analysing rooms…* / *正在辨認房間…*), applying plan layers, and updating isolines (*Updating isolines…* / *正在更新等照度線…*). It stays until the result is ready to use, and cannot be dismissed by clicking the backdrop or a close button. It does not appear for pan, zoom, selection, orbiting the 3D view, or typing in property fields. The official project file extension is .lxm. **Save .lxm** in Documentation mode opens a save-path dialog (when the browser supports it) so you choose the folder and file name, then writes ProjectName.lxm including the plan underlays the project uses. Cancelling the dialog does not also download the file. If the browser has no such dialog, the file is downloaded to the browser’s download folder. **Open .lxm** on a new account or workspace restores those drawings with their scale and placement, so you do not need to re-upload them. Older files without embedded drawings still open, and older .lux, .luxsim and .luxsim.json files still open. Rooms, fixtures, results, and photometry are kept, and a missing plan is not invented.


## 儲存提醒 / Save reminder

編輯器不會在背景自動儲存。若專案有未儲存的變更，會依帳戶設定的間隔（預設 15 分鐘；可在標題列 **Account settings** 設為關閉、1、5 或 15 分鐘）出現提醒對話框，說明請儲存檔案。按 **Save** 會以與工具列相同的方式儲存並關閉對話框，計時重新開始。按 **Later**、Esc 或點背景則先不儲存；若之後仍有未儲存變更，會再等一個完整間隔才再次提醒。關閉提醒後，仍可隨時按工具列的 **Save**。把提醒設為 Off 後不會再跳出對話框，但仍可按 **Save**。同一個 **Account settings** 裡可開啟或關閉 **View-only project links**（只讀專案連結，預設開啟）。開啟時，每個專案可在 **Documentation** 模式產生只讀連結與 QR 碼。訪客可瀏覽專案（切換視圖、平移縮放、查看屬性與照度顯示），但不能儲存或編輯：輸入欄位會顯示為純文字，新增樓層、工具、刪除與拖放燈具都不可用；你仍可在該專案單獨關閉分享。關閉帳戶開關後，既有專案也不會公開，直到再次開啟。

The editor does not silently autosave. When there are unsaved changes, a reminder dialog appears after the interval set in header **Account settings** (default 15 minutes; Off / 1 / 5 / 15 minutes). It asks you to save the file. **Save** runs the same official save as the toolbar, then closes the dialog and resets the timer. **Later**, Esc, or clicking the backdrop dismisses it without saving; if the project is still dirty, you are reminded again after another full interval. You can still click **Save** in the toolbar at any time. Off means no reminder; you can still click **Save**. The same **Account settings** panel has **View-only project links**, which is on by default. When it is on, each project can show a link and a QR code in **Documentation**. Visitors can browse (switch views, pan and zoom, and read properties and illuminance displays), but they cannot save or edit: fields are shown as text, and adding storeys, construction tools, Remove, and dragging fixtures are unavailable. You can still turn sharing off for one project. When the account setting is off, existing projects stay private until you turn it on again.

## 工作區名稱 / Workspace name

工作區的 Owner 可在 [Workspace members](/workspace/members) 頁將工作區重新命名。按名稱旁的鉛筆圖示，輸入新名稱後按 **Save**；按 **Cancel** 則不更改。名稱不能空白，亦不可超過 100 個字元。同一個工作區若有多於一位 Owner，任何一位現任 Owner 都可以改名。Member 不能更改工作區名稱，也打不開此頁。

The workspace Owner can rename the workspace on the [Workspace members](/workspace/members) page. Click the pencil icon next to the name, enter the new name, then **Save**. **Cancel** leaves the name unchanged. The name cannot be empty or longer than 100 characters. If a workspace has more than one Owner, any current Owner may rename it. Members cannot rename the workspace, and they cannot open this page.

## 平面圖視野 / Plan view

![平面視野控制 / Plan view controls](/docs/guide/plan-view-controls.svg)

![房間角點控制點 / Room corner and edge handles](/docs/guide/room-handles.svg)

在 **Top**、**Front**、**Side** 與 **3D** 視圖：

- 在圖面上滾動滑鼠滾輪，會放大或縮小（平面與立面以游標位置為中心），不會捲動整頁。平面縮放範圍約為 0.25× 至 128×，方便在細密的天花圖上描角點。畫房或畫樓層輪廓的草稿進行中，滾輪縮放不會重設視野。
- 按住滑鼠中鍵（滾輪按鈕）並拖曳，可在 Top、Front、Side 與 3D 視圖平移圖面，放大靠近房間時同樣可以。視圖會即時跟隨游標，瀏覽器不會因此出現中鍵自動捲動。不要用左鍵平移：左鍵仍用於點選、畫房或移動燈具。房間不能整間拖移；選取房間後仍可拖動角點或在邊上插入角點來改形狀。
- 在 **Top** 雙擊圖面空白處，會回到預設的置中適合視野。
- 切換樓層時，視野也會回到這個預設。
- 畫房途中，自動套圖保持鎖定，點擊位置不會因為草稿而偏移；滾輪縮放與中鍵平移仍可使用。
- **Top**／**Front**／**Side**／**3D** 切換與 **Fullscreen** 會連同等照度線或 3D 顯示開關，一起浮在圖面左上角，讓圖面本身有較大的操作面積。編輯器沒有 Bottom 視圖按鈕；報告若需要由下向上的投影，仍可在匯出時使用。
- 切換 **Top**、**Front**、**Side** 或 **3D** 時，會顯示官方 **Loading…**／**正在載入…** 對話框，直到新視圖畫完。第一次開啟 **3D** 時會建立立體場景；之後從 **Top**、**Front** 或 **Side** 再切回 **3D**，會沿用已建立的場景，不必整段重建，載入對話框通常會短很多。平移、縮放與環視不會顯示這個對話框。若沒有樓層輪廓，也沒有任何房間，按 **3D** 會跳出對話框，說明請先建立模型（請先新增樓層輪廓或至少一個房間），並且不會切換視圖；按 **OK**、Esc 或點背景即可關閉。已在 3D 時再按 **3D** 不會再跳出。**Front** 與 **Side** 不會因此被阻擋。有樓層輪廓或至少一個房間時，即可開啟 **3D**。開啟後，若該層有有效樓層輪廓，即使還沒有房間，3D 也會以樓板與青綠色輪廓／樓層高度帶顯示該輪廓，並把攝影機對準輪廓（以及已有的房間與燈具），不會對準遠處的原點。**Front** 與 **Side** 同樣會以青綠色虛線立面範圍顯示該輪廓。輪廓仍然不是房間，不會出現在房間列表或計算中。
- 房間不能整間拖移，整層也不能用拖曳來平移。選取房間後，可用角點控制點拉伸，或在邊上插入角點。平移圖面請按住滑鼠中鍵拖曳。
- 一般視圖（不必開 Fullscreen）下，2D／3D 畫布會留在視窗內完整可見。左、右、底部面板只在對應的工作分頁出現；該分頁沒有內容的左欄或右欄會整欄收起，畫布會跟著加寬。有顯示的左側欄、右側欄與底部面板可以最小化並還原；最小化後內容會隱藏，畫布加寬，並留下可還原的窄條。沒有內容或不屬於該分頁的欄不會留下還原條。狀態列與只在 Calculation 出現的偽色／灰階刻度條不變。有顯示的右側屬性／工具欄若內容較長，會在欄內捲動，不會把圖面推走或裁掉。左側 Building 樹過長時同樣在欄內捲動。
- 若目前樓層的官方底圖是已解析的 DXF，在 **Top** 上進行點選時，游標會在目前縮放下 8 個 CSS 像素範圍內，吸附到線段端點、中點，或線段上最近的一點，並顯示對應標記；超出範圍時標記會消失。圖像或 PDF 底圖不會做像素吸附。匯入的 DWG 會先轉換成與 DXF 相同的描線，之後可顯示、吸附，並可用 **Create rooms from DXF** 由描線建立房間。沒有 DXF 或已轉換的 DWG 底圖、或沒有線段時，吸附不會啟動，也不會發明幾何。若目前樓層的底圖是 DXF，或是已轉換並含描線的 DWG，可用 **Create rooms from DXF** 先以完整匯入圖則（包括目前在圖則圖層中隱藏的建築圖層）的外圍樓板輪廓建立或更新樓層輪廓（明確按此命令時，會取代先前自動建立的輪廓，不會把內庭或其他內部空洞當成樓板），再尋找房間或建築佈局（不是燈具或天花格網），並從佈局圖層上的封閉折線、簡單閉合迴路或牆網絡房間面，或非均勻小格網的房間大小封閉形狀，建立面積不少於 1 m² 的房間。隱藏牆身或建築圖層以便檢視照明圖則，不會阻止程式用這些圖層偵測房間。官方房間是無洞的簡單多邊形：若一間房完全落在另一間之內且沒有連牆，只保留內房。CIRCLE、ARC、ELLIPSE、SPLINE（包括只有擬合點的 SPLINE）、舊式 POLYLINE 與 LWPOLYLINE 凸度也會描繪（曲線以多邊形近似）。非網格的 3D POLYLINE 會按平面描繪（忽略 Z）。圖紙空間實體（群組碼 67 = 1）不會顯示、吸附、計入範圍，也不會用來建立房間。多邊形網格與多面網格 POLYLINE 也會按平面描繪（忽略 Z），並可用來建立房間。CIRCLE、ARC、ELLIPSE、LWPOLYLINE 與二維 POLYLINE 的 3D extrusion（群組碼 210/220/230）會在平面描繪時套用。LINE、SPLINE、3D POLYLINE 與網格頂點仍用世界座標；轉換後仍忽略 Z。新房間使用官方預設，比例跟隨目前的 **Calibrate scale**。
- 新匯入的 DXF 或已轉換的 DWG，若圖紙標明單位（例如公釐），會自動換成公尺；沒有標單位或標為無單位時，仍以 1 個繪圖單位為 1 公尺，不必先校正即可畫房。INSERT 圖塊會依插入點、比例與旋轉展開到圖則上；圖塊定義本身不會畫在定義座標。平面視圖會對準圖則的主要範圍，遠處的零星點不會把第一次顯示縮成一點。若使用官方 **Calibrate scale** 兩點校正，DXF 描線與吸附點會一併按同一比例縮放（兩個軸使用同一個 `metersPerUnit`）。既有房間多邊形和燈具的世界座標已是公尺，不會再乘這個比例。

On the **Top**, **Front**, **Side**, and **3D** views:

- Scroll the mouse wheel on the view to zoom (toward the cursor on the plan and elevation views). The page itself does not scroll. Plan zoom ranges from about 0.25× to 128× so you can pick corners on a dense reflected-ceiling plan. Wheel zoom does not reset the view while a Draw room or Draw storey contour draft is in progress.
- Hold the middle mouse button (the scroll-wheel button) and drag to pan the view in Top, Front, Side, and 3D, including when you have zoomed in on a room. The view follows the pointer immediately, and the browser does not start middle-click autoscroll. Do not pan with the left button: left-click still selects, draws rooms, or moves a fixture. Rooms cannot be dragged as a whole; after a room is selected you can still drag a corner handle or insert a vertex on an edge.
- Double-click an empty area of the **Top** plan to return to the default centred fit.
- Switching storeys also resets the view to that default fit.
- While you are drawing a room, the automatic fit stays locked so click positions remain stable. Wheel zoom toward the cursor and middle-button pan still work.
- The **Top** / **Front** / **Side** / **3D** tabs and **Fullscreen** sit together as floating controls at the top left of the plan, with the Isolines or 3D display toggles, so more of the canvas is available as operating area. There is no Bottom view button in the editor; a bottom projection, if needed, is kept for PDF / capture export.
- Switching between **Top**, **Front**, **Side**, and **3D** shows the official **Loading…** dialog until the new view has been drawn. The first time you open **3D**, the editor builds the 3D scene. After that, switching back from **Top**, **Front**, or **Side** keeps that scene instead of rebuilding it, so the Loading dialog is usually much shorter. Panning, zooming, and orbiting do not show this dialog. If there is no storey contour and no room has been built, clicking **3D** opens a dialog that explains the model must be built first (add a storey contour or at least one room), and does not switch the view. **OK**, Esc, or clicking the backdrop dismisses it. Clicking **3D** again while already in 3D does not re-open the dialog. **Front** and **Side** are not blocked this way. A storey contour alone, or at least one room, is enough to open **3D**. When a valid storey contour exists, the 3D view shows it as a floor plate and a teal outline / storey-height ribbon even if there are no rooms, and fits the camera to the contour (together with any rooms and fixtures) rather than to a distant origin. **Front** and **Side** also show the contour as a teal dashed elevation span. The contour is still not a room, and is not listed in the room tree or included in calculation.
- Rooms cannot be dragged as a whole, and a storey cannot be dragged on the plan. After a room is selected, drag a corner handle to stretch it, or use the mid-edge handle to insert a vertex. A click on a room still selects that room. Hold the middle mouse button to pan the view.
- In the normal (non-fullscreen) editor view, the 2D and 3D canvas stays fully visible in the window. Left, right, and bottom panels appear only on the matching workflow tab; if a tab has no content for a rail, that rail hides and the canvas grows. Visible left and right rails and the bottom panels can be minimized and restored: minimizing hides that panel’s content and grows the canvas, and a compact restore control remains. A rail the current tab has no content for still hides completely, with no restore strip. The status bar and the Calculation-only false-colour / greyscale scale bar are unchanged. If a visible right-hand Properties / tools rail is longer than the column, it scrolls inside the rail instead of pushing or cropping the plan. You do not need **Fullscreen** just to see the plan. A long Building tree on the left also scrolls inside its column.
- When the active storey’s official underlay is a parsed DXF, picks on the **Top** plan snap to endpoints, midpoints, and the nearest point on a segment within 8 CSS pixels at the current zoom. A small marker shows the active snap kind, and disappears when none is in range. This applies to Draw room corners, Calibrate scale clicks, Line-array endpoints, Circle-array centres, Polygon-array custom-path vertices, fixture drop placement, and dragging a room corner handle. **Create rectangle** still places a room at `(0, 0)` and does not pick on the plan. Image and PDF underlays do not get raster snap. A DWG import is converted and then works like a DXF underlay: it can be displayed, snapped, and used to create rooms from the linework. If there is no DXF or converted DWG underlay, or the entities are empty, snap stays inactive and no geometry is invented. With a DXF underlay or a converted DWG underlay that has linework, **Create rooms from DXF** first builds or updates the storey contour from the outer floor-plate boundary of the full imported drawing, including layers currently hidden by Plan layers (an explicit run of this command replaces a previously auto-built contour; an inner courtyard or other void is not used as the plate), then looks for a room or architectural layout — not a lighting or ceiling grid — and creates rooms of at least 1 m² from closed polylines, simple closed loops, or wall-network faces on layout layers, or from room-sized closed shapes that are not a uniform small grid. Hiding walls or architectural layers to view the lighting plan does not stop room detection from using those layers. Official rooms are simple polygons without holes: if one room lies fully inside another with no connecting wall, only the inner room is kept. CIRCLE, ARC, ELLIPSE, SPLINE (including a spline that has only fit points), old POLYLINE, and LWPOLYLINE bulges are also traced (curves as polygons). A non-mesh 3D POLYLINE is traced in plan (Z is ignored). Paperspace entities (group 67 = 1) are not displayed, snapped, bounded, or used to create rooms. Polygon-mesh and polyface-mesh POLYLINE entities are also traced in plan (Z is ignored). A 3D extrusion (groups 210/220/230) on CIRCLE, ARC, ELLIPSE, LWPOLYLINE, and 2D POLYLINE is applied when tracing in plan. LINE, SPLINE, 3D POLYLINE, and mesh vertices stay in world coordinates; Z is still ignored after the transform. New rooms use the official defaults, and scale follows the current **Calibrate scale**.
- A newly imported DXF or converted DWG uses the drawing’s declared units (for example millimetres) so the plan is in metres. If units are missing or unitless, it starts at 1 metre per drawing unit, and Draw room stays allowed without a prior calibrate. Block references (INSERT) are exploded onto the plan at their insertion point, scale, and rotation; block-definition geometry is not drawn at its definition coordinates. The plan view fits the main extent of the drawing so a few far-away points do not shrink the first view. Official **Calibrate scale** (two points plus a real length) resizes the DXF drawing and the snap points together, using the same uniform `metersPerUnit` on both axes. Existing room polygons and fixture world coordinates are already in metres and are not multiplied by that scale.

放大後，圖面角落會提示 *double-click empty area to reset*。

When zoomed in, the plan shows the hint *double-click empty area to reset*.

## 工作分頁與面板 / Workflow panels

編輯器頂部的 **Construction**、**Light**、**Calculation**、**Documentation** 分頁決定左側、右側與底部面板要顯示什麼。左側欄是主要面板：若某個分頁只有一個面板，會放在左側，不會只出現在右側。切換分頁時，左側欄寬度保持不變，畫布左緣不會跳動。沒有內容的左欄或右欄會整欄收起，畫布會跟著加寬。有顯示的左側欄、右側欄，以及底部的 Light **Fixtures in project** 表與 Calculation 結果列，都可以最小化並還原：最小化後該面板內容會隱藏，畫布加寬，並留下可還原的窄條。此偏好只保存在此瀏覽器，不會寫入專案檔。沒有內容或不屬於該分頁的左欄或右欄仍會整欄隱藏，不會留下還原條。頂部分頁、Undo／Redo／Save、狀態列，以及圖面上的 **Top**／**Front**／**Side**／**3D** 與偽色／灰階／等照度線／數值／工作面顯示開關，在每個分頁都保持可用。狀態列與只在 Calculation 出現的偽色／灰階刻度條不能用這個方式最小化，外觀也不變。**Calc room**／**Calc storey**／**Calc all** 仍在頂部工具列。已開啟的偽色或灰階疊加在其他分頁仍會顯示，但圖面下方的偽色／灰階刻度條只在 **Calculation** 分頁出現。

- **Construction**：左側為 **Import plan**（含目前檔案、透明度、PDF 頁、Plan layers；唯讀時仍可看檔案與圖層並下載圖則）、Building 樹、Add／Copy storey（唯讀時隱藏）、樓層標高與層高、**Room height**，以及所有建模 Tools。右側只在已選房間且未選燈具時顯示建模屬性：名稱、高度、面積、原點、Bounding min，以及 ρ 地板／天花／牆面；不顯示工作面、網格間距或維護係數。選取燈具不會改動目前房間，也不會在此分頁顯示燈具屬性。沒有可顯示的右側內容時，右欄會收起。此分頁沒有專案燈具表、計算結果列或刻度條。
- **Light**：左側只保留 Building 樹，方便選樓層或房間（仍會提示先選房間）。右側為 **Fixture library**（含 Add from org library、Upload、Generate LDT 對話框；唯讀時隱藏這些編輯操作）、佈燈工具，以及選取燈具後的屬性（位置、旋轉、光束錐預覽）。底部只在此分頁顯示 **Fixtures in project** 表。不顯示計算結果列或刻度條。
- **Calculation**：左側同樣只有 Building 樹，用來選要查看結果的房間或樓層。右側為 Isoline levels（預設收合），以及選取房間後的計算屬性：房間名稱與面積（供對照）、**Workplane (m)** 與 **Show**、網格間距、維護係數／CIE 97，以及 EN 12464-1 assist。底部為此分頁的計算結果列。偽色／灰階刻度條只在此分頁、並且既有顯示條件成立時出現（Top 已開偽色且有結果，或 3D 為偽色／灰階）。
- **Documentation**：左側顯示 **Documentation & export**（Project share、Full PDF report、Save .lxm、Verification pack），不顯示 Building 樹或 Import plan。右欄完全隱藏，不會留下空白右側條。沒有燈具表、計算結果列、刻度條或燈具庫。

The **Construction**, **Light**, **Calculation**, and **Documentation** tabs at the top of the editor control what the left, right, and bottom panels show. The left rail is the primary panel: a tab that has only one panel shows it on the left, never as a right-only layout. The left rail width stays the same when you switch tabs, so the left edge of the canvas does not jump. If a rail has no content on that tab, it hides and the canvas grows. Visible left and right rails, and the bottom panels (the Light **Fixtures in project** table and the Calculation results strip), can be minimized and restored. Minimizing hides that panel’s content and grows the canvas; a compact restore control remains so you can bring it back. This preference stays in this browser and is not written into the project file. A rail that the current tab has no content for still hides completely — there is no restore strip for a rail the tab does not own. The top tabs, Undo / Redo / Save, the status line, and the on-canvas **Top** / **Front** / **Side** / **3D** view plus false colour / greyscale / isolines / labels / workplane display toggles stay available on every tab. The status bar and the Calculation-only false-colour / greyscale scale bar are unchanged, and are not minimized with these controls. **Calc room** / **Calc storey** / **Calc all** stay in the ribbon. False-colour or greyscale overlays you already turned on remain visible on other tabs; the false-colour / greyscale scale bar under the view appears only on **Calculation**.

- **Construction**: the left rail has **Import plan** (including the current file, opacity, PDF page, and Plan layers; view-only still shows the plan file and layer list, and plan download stays allowed), the Building tree, Add / Copy storey (hidden when view-only), storey elevation and height, **Room height**, and all modelling Tools. The right rail shows modelling room properties only when a room is selected and no fixture is selected: name, height, area, origin, Bounding min, and ρ floor / ceiling / walls. Workplane, grid spacing, and maintenance factor are not shown here. Selecting a fixture does not change the active room, and fixture properties are not shown on this tab. If the right rail would be empty, it hides. This tab has no fixtures table, results strip, or scale bar.
- **Light**: the left rail keeps only the Building tree, so you can still select a storey or room (the existing prompt to select a room still applies). The right rail has **Fixture library** (Add from org library, Upload, and the Generate LDT dialog; view-only hides those edit controls), the light-placement tools, and the selected-fixture properties (position, rotation, light cone preview). The **Fixtures in project** table appears at the bottom on this tab only. There is no results strip or scale bar.
- **Calculation**: the left rail is the same slim Building tree, so you can pick the room or storey whose results are shown. The right rail has Isoline levels (collapsed until you click the heading) and, when a room is selected, calculation properties: room name and area for context, **Workplane (m)** with the **Show** checkbox, grid spacing, maintenance factor / CIE 97, and EN 12464-1 assist. The results strip is at the bottom on this tab only. The false-colour / greyscale scale bar appears only here, and only when the existing display conditions are also met (Top view with false colour and results, or 3D false colour / greyscale).
- **Documentation**: the left rail shows **Documentation & export** (Project share, Full PDF report, Save .lxm, Verification pack), not the Building tree or Import plan. The right rail is hidden completely — there is no empty right strip. There is no fixtures table, results strip, scale bar, or Fixture library.

## 匯入圖則 / Import plan

在 **Construction** 模式，左側面板最上方是 **Import plan**，可匯入圖像、PDF、DXF、DWG 或 IFC 圖則。匯入 DWG 後會轉換成與 DXF 相同的描線，可用來顯示、吸附，並以 **Create rooms from DXF** 由描線建立房間。匯入成功後，該區會顯示檔名和上傳日期時間（香港時間），旁邊有 **Download**，可下載目前匯入的圖則原檔（即已上傳並儲存的原檔，不是按可見圖層另外產生的 DWG 或 DXF）。按 **Apply** 開關圖層不會改寫已儲存的檔。重新匯入更新後的圖則後，下載的是新上傳的檔。檔案選擇框會清空，方便再選同一個檔。若圖則是 DXF 或已轉換的 DWG，**Import plan** 下方會列出圖層，可像 CAD 一樣開關。匯入後預設全部圖層開啟。勾選後按 **Apply** 才會抽出可見圖層並壓縮描線（約 1.5 mm 容差，只合併近共線頂點和明顯重疊的線段），期間會顯示官方 **Loading…**／**正在載入…** 對話框。隱藏的圖層不會顯示，也不會被物件吸附。即使按 **Select none** 再 **Apply**、把全部圖層隱藏，圖層清單仍會保留，方便再勾選或按 **Select all** 後套用還原。稍後再開啟已隱藏的圖層並按 **Apply**，會從已儲存的原圖則檔還原完整描線。開啟專案時只載入上次套用後的可見描線與圖層表，不會每次都把完整 CAD 實體一併載入，所以套用圖層後再開專案會快得多。重新匯入圖則會依新檔重置圖層。在圖層名稱被儲存之前就已匯入的舊圖則，開啟專案並進入 **Construction** 時，會從原本儲存的檔案再讀一次圖層，期間顯示官方載入對話框；讀取後的圖層清單會與 CAD 檔一致。若檔案本身只有圖層 0，清單仍只顯示一層。成功匯入 DXF 或 DWG，且目前樓層尚無房間時，會先詢問你要自行建立樓層和房間，還是由這份圖則自動建立。選「我自己建立」（或按 Esc、點背景）則只保留已匯入的圖則，可用 **Draw room**、**Draw storey contour** 或 **Create rooms from DXF**；選「從圖則建立」則使用與 **Create rooms from DXF** 相同的路徑：先以完整匯入圖則（包括目前在圖則圖層中隱藏的建築圖層）的外圍樓板輪廓建立或更新樓層輪廓（會取代先前自動建立的輪廓，不會把內庭或其他內部空洞當成樓板），再尋找房間佈局。隱藏牆身或建築圖層以便檢視照明圖則，不會阻止程式用這些圖層偵測房間。若已從圖則找到部分房間，且網站管理員已在 Settings 啟用房間辨認 AI 並儲存金鑰，仍可再辨認樓層輪廓內尚未覆蓋的空間；若找不到佈局，才會把整段輪廓交由 AI 辨認房間。輪廓與新房間為同一步復原。若該層已有房間，不會再詢問，也不會自動加房。圖像、PDF 或 IFC 匯入不會出現此詢問；唯讀也不會。手動的 **Create rooms from DXF** 掣仍在 Construction 左側 Tools（Create rectangle 下方），沒有 CAD 描線時為灰色。唯讀檢視時，**Import plan** 會隱藏，但仍可看到目前哪些圖層是開啟的，也可下載目前圖則；不能上傳。**Light** 模式同樣隱藏匯入區。

In **Construction** mode, **Import plan** is at the top of the left panel. Use it to import an image, PDF, DXF, DWG, or IFC plan. A DWG import is converted and then works like a DXF underlay (display, snap, and create rooms from the linework). After a successful import, the section shows the file name and the upload date and time (Hong Kong time), with a **Download** control that saves the current imported plan — the already uploaded and stored original file, not a new DWG or DXF generated from the visible layers. Clicking **Apply** on plan layers does not rewrite the stored file. After you re-import an updated plan, Download follows the new file. The file picker itself is cleared so you can choose the same file again. For a DXF, or a converted DWG, a **Plan layers** list appears under Import plan so you can turn layers on or off like CAD. All layers start visible. Tick the layers you want, then click **Apply** — the editor extracts those layers and compresses the linework (about 1.5 mm tolerance, merging near-collinear vertices and obviously duplicate overlapping segments). The official **Loading…** dialog is shown while that runs. Hidden layers are not drawn and are not object-snapped. If you click **Select none** and then **Apply**, the Plan layers list stays on screen so you can tick layers or **Select all** and apply again. Turning a hidden layer back on and clicking **Apply** restores it from the stored original plan file. Opening a project uses the last applied visible linework and the layer list, and does not load the full CAD entity source until you click **Apply** again, so projects open much faster after a layer change. Re-importing a plan resets the layers from the new file. Older plans imported before layer names were stored are re-read from the original file when the project is opened in **Construction**, and the official loading dialog is shown while that runs, so the layer list matches the CAD file. A file that genuinely has only layer 0 still shows one layer. After a successful DXF or DWG import, if the active storey currently has no rooms, a dialog asks whether you want to build the storey and rooms yourself, or create them from this plan. **I'll build them** (or Esc / backdrop click) keeps only the imported plan so you can use **Draw room**, **Draw storey contour**, or **Create rooms from DXF**. **Create from plan** uses the same path as **Create rooms from DXF**: it first builds or updates the storey contour from the outer floor-plate boundary of the whole building (replacing a previously auto-built official contour; an inner courtyard or other void is not used as the plate), then searches the full imported drawing for a room layout, including layers currently hidden by Plan layers. Hiding walls or architectural layers to view the lighting plan does not stop room detection from using those layers. If some rooms are found locally, AI may still be used for remaining space inside the contour when Room-analysis AI is enabled; if no layout is found, it tries AI for the whole contour (when a site administrator has enabled it and saved a key in Settings). The contour and any new rooms are one undo step. Re-import onto a storey that already has rooms does not show the dialog and does not auto-add rooms. Image, PDF, and IFC imports do not ask; view-only never asks. The manual **Create rooms from DXF** button remains in Construction left Tools (below Create rectangle) and stays disabled without CAD linework. In view-only, Import plan stays hidden, but you can still see which layers are on and download the current plan. You cannot upload a plan in view-only. In **Light** mode the section stays hidden, as it does today.

## 畫房 / Draw room

![畫房步驟 / Draw room on the plan](/docs/guide/draw-room.svg)

在 **Construction** 模式，選 **Draw room**，於 **Top** 視圖操作：

1. 左鍵逐點點出房間角點。
2. 用鍵盤輸入長度（預設單位是毫米）。下一個角點會鎖在以上一點為圓心、該長度為半徑的圓上，游標只決定方向。
3. 按住 **Shift** 可限制為水平或垂直。
4. 把游標移近第一個角點（約 12 個 CSS 像素內）再點一下，或在顯示 *click to close* 時按 **Enter**，即可封閉房間。封閉時會使用正確的起點，不會多加一個偏移點。若游標已在起點吸附範圍內，會優先封閉，而不使用 DXF 物件吸附或正交／鎖定長度。少於 3 個角點時不能封閉。
5. 若已輸入並鎖定長度，按一次 **Backspace** 會整段清掉該長度，再按一次才撤回上一個角點。
6. 畫房途中按 **Esc** 會取消草稿。即使瀏覽器處於全畫面，也不會因此退出全畫面。沒有草稿時，**Esc** 仍可用來退出全畫面。

If the plan underlay is an image or PDF that has not been calibrated, drawing a room or creating a rectangle is blocked until you use **Calibrate scale**. The status bar then says: *Calibrate scale first — the plan underlay is a preview size until you set a real distance.* You can draw with no underlay, a DXF underlay, a converted DWG underlay, or a calibrated plan. A new DXF still starts at 1 metre per drawing unit. After official **Calibrate scale** on a DXF underlay, the drawing and the snap points resize together. With a DXF underlay or a converted DWG underlay, official Top picks (including Draw room corners and Calibrate scale clicks) snap to endpoints, midpoints, and the nearest point on a segment within 8 CSS pixels. **Create rooms from DXF** first builds or updates the storey contour from the outer floor-plate boundary of the full imported drawing, including layers currently hidden by Plan layers (an explicit run of this command replaces a previously auto-built contour; an inner courtyard or other void is not used as the plate), then looks for a room or architectural layout — not a lighting or ceiling grid — and creates rooms of at least 1 m² from closed polylines, simple closed loops, or wall-network faces on layout layers, or from room-sized closed shapes that are not a uniform small grid. Hiding walls or architectural layers to view the lighting plan does not stop room detection from using those layers. Official rooms are simple polygons without holes: if one room lies fully inside another with no connecting wall, only the inner room is kept. CIRCLE, ARC, ELLIPSE, SPLINE (including a spline that has only fit points), old POLYLINE, and LWPOLYLINE bulges are also traced (curves as polygons). A non-mesh 3D POLYLINE is traced in plan (Z is ignored). Paperspace entities (group 67 = 1) are not displayed, snapped, bounded, or used to create rooms. Polygon-mesh and polyface-mesh POLYLINE entities are also traced in plan (Z is ignored). A 3D extrusion (groups 210/220/230) on CIRCLE, ARC, ELLIPSE, LWPOLYLINE, and 2D POLYLINE is applied when tracing in plan. LINE, SPLINE, 3D POLYLINE, and mesh vertices stay in world coordinates; Z is still ignored after the transform. New rooms use the official defaults (maintenance factor 0.80, no EN template, and the Building Room height). Scale follows the current **Calibrate scale**.

房間建立後，不能在平面上整間拖移該房。選取房間後，可在 **Select** 工具下用角點控制點拉伸形狀，或在邊上插入角點。單一燈具仍可用 **Select / move** 單獨拖移。平移圖面請按住滑鼠中鍵拖曳。

若已選房間，該房每個角點會出現控制點，邊上亦會出現較小的插入控制點。拖移角點控制點可在世界 XY 平面拉伸該既有角，其餘角點不動。拖移邊上的插入控制點，會在該邊最接近的位置加入新角點，並可在同一拖移中放到目標位置。若有 DXF 底圖，插入與拖移時會使用同一套物件吸附（目前縮放下 8 個 CSS 像素內的端點、中點或線段上最近點）；沒有吸附時，新角點先落在該邊上最接近游標的位置，其後跟隨游標的世界座標。靠近既有角點的位置不會插入，以免搶走角點控制點。在房間填色範圍內拖移不會再移動整個房間。若插入或拉伸後房間少於 3 個不重複角點、輪廓自交，或面積小於 0.01 m²，會還原到插入或拖移前的多邊形（不會留下多出來的頂點），並在狀態列說明原因。將游標移到角點控制點上，或先點一下該控制點但不拖移以選取該角，再按 Delete 或 Backspace，即可刪除該角點。邊上的插入控制點不能刪除。只選了房間但未指定要刪的角點時按 Delete，不會刪除任何角，狀態列會提示先選擇角點。若刪除後房間少於 3 個不重複角點、輪廓自交，或面積小於 0.01 m²，則不改房間，並在狀態列說明原因。畫房草稿進行中，Backspace 仍會先清掉鎖定長度，再撤回上一個草稿角，行為不變。

在左側 **Building** 樹選取樓層時，在該層房間填色範圍上拖曳也不會移動整層。點一下房間仍會選取該房間。這不是平移圖面：左鍵在空白處拖曳仍不會移動視野；按住滑鼠中鍵拖曳才會平移。

在 **Construction** 分頁左側 **Building** 面板可設定 **Room height**（毫米，預設 2800）。未選房間時此欄仍可見，會用於下一間用 **Draw room**、**Create rectangle** 或 **Create rooms from DXF** 建立的房間。若已選房間，改此欄也會更新該房的天花板高度，其他房間不變。

矩形房間：在工具列輸入 **Length** 和 **Width**（毫米，或加 `m` / `cm` 後綴）後建立，房間會放在樓層原點 `(0, 0)`。高度取自 **Room height**。建立後可用角點控制點調整形狀；不能整間拖移到圖則位置。

若目前樓層的底圖是已解析的 DXF，或是已轉換並含描線的 DWG，工具列的 **Create rooms from DXF** 會先以完整匯入圖則（包括目前在圖則圖層中隱藏的建築圖層）的外圍樓板輪廓建立或更新樓層輪廓（明確按此命令時，會取代先前自動建立的輪廓，不會把內庭或其他內部空洞當成樓板），再尋找房間或建築佈局（例如 WALL、A-WALL、ROOM、PARTITION、FLOOR、LAYOUT、PLAN、牆、房間等圖層），而不是燈具或天花格網（CEILING、GRID、TILE、LIGHT、FIXTURE 等）。房間來自這些佈局圖層上的封閉折線、簡單閉合迴路或牆網絡房間面，或來自不是均勻小格網的房間大小封閉形狀。隱藏牆身或建築圖層以便檢視照明圖則，不會阻止程式用這些圖層偵測房間。自動建立的房間面積須至少 1 m²（典型 600×600 mm 天花格片會被略過，小型洗手間仍可通過）；若線條是大量相近的小矩形格網，會整組略過，而不是每格一間房。手動 **Draw room** 的最小面積仍為 0.01 m²。官方房間是無洞的簡單多邊形：若一間房完全落在另一間之內且沒有連牆，只保留內房。CIRCLE、ARC、ELLIPSE、SPLINE（包括只有擬合點的 SPLINE）、舊式 POLYLINE 與 LWPOLYLINE 凸度也會描繪（曲線以多邊形近似）。非網格的 3D POLYLINE 會按平面描繪（忽略 Z）。圖紙空間實體（群組碼 67 = 1）不會顯示、吸附、計入範圍，也不會用來建立房間。多邊形網格與多面網格 POLYLINE 也會按平面描繪（忽略 Z），並可用來建立房間。CIRCLE、ARC、ELLIPSE、LWPOLYLINE 與二維 POLYLINE 的 3D extrusion（群組碼 210/220/230）會在平面描繪時套用。LINE、SPLINE、3D POLYLINE 與網格頂點仍用世界座標；轉換後仍忽略 Z。新房間使用官方預設（維護係數 0.80，不繼承所選房間的 EN 範本），高度取自 **Room height**，比例跟隨目前的 **Calibrate scale**。既有房間不會被改寫。搜尋房間時會使用完整匯入圖則，包括目前隱藏的建築圖層。若已從圖則找到部分房間，且網站管理員已在 **Admin → Settings** 啟用 Room-analysis AI 並儲存金鑰，仍可再辨認樓層輪廓內尚未覆蓋的空間（等待對話框顯示「Analysing rooms…／正在辨認房間…」）。若找不到佈局，也會在已啟用 AI 時交由 AI 辨認。若尚未設定 AI，狀態列會說明須由網站管理員在 **Admin → Settings** 啟用 Room-analysis AI 並儲存 API 金鑰；已找到的房間和已建立或更新的樓層輪廓會保留，不會刪除，也不會新增無效房間。輪廓與新房間為同一步復原。

若要合併目前樓層上兩間重疊、或沿邊相接的房間，可在 Construction tools 按 **Union rooms**。在 **Select** 閒置時，若已選一間房，該房會作為保留的第一間，再於平面上點選第二間；若尚未選房，則依次點選兩間。按 **Esc** 可取消點選。第一間房會保留其識別碼、名稱、維護係數、EN 範本、高度及其他官方房間屬性；成功合併後第二間房會被移除。若兩房不在目前樓層、其中一間缺失、只在點上相觸或完全不相接，或合併結果會形成洞、自交、少於 3 個不重複角點、面積小於 0.01 m²，或無法得到單一簡單輪廓，指令會被拒絕，房間不變，並在狀態列說明原因。屬於被移除房間、且 XY 仍在合併後輪廓內的燈具會改歸保留房間；落在輪廓外的燈具留在該層並取消房間歸屬，燈具不會被刪除。計算結果會留在原位，直到再按 Calculate。一次成功合併可用 **Ctrl+Z** 整步撤銷。對齊不包括在內。

若要把目前樓層上一間房從另一間切走，可在 Construction tools 按 **Subtract rooms**。在 **Select** 閒置時，若已選一間房，該房會作為保留並被切割的第一間，再於平面上點選作為切割器的第二間；若尚未選房，則依次點選兩間。按 **Esc** 可取消點選。第一間房會保留其識別碼、名稱、維護係數、EN 範本、高度及其他官方房間屬性，輪廓改為「第一間減第二間」的單一外輪廓。切割器房間會留在原位，不會被刪除。若兩房不在目前樓層、其中一間缺失、兩次點到同一間房、面積沒有重疊（只沿邊相觸或完全不相接不算切割），或結果會變成空、裂成兩塊或以上互不相連的部分、形成洞、自交、少於 3 個不重複角點、面積小於 0.01 m²，或無法得到單一簡單輪廓，指令會被拒絕，房間不變，並在狀態列說明原因。屬於保留房間、且 XY 已不在切割後輪廓內的燈具會取消房間歸屬；切割器房間的燈具不變。燈具不會被刪除。計算結果會留在原位，直到再按 Calculate。一次成功差集可用 **Ctrl+Z** 整步撤銷。此增量不包括對齊。

若要把目前樓層上兩間房的重疊部分留下，可在 Construction tools 按 **Intersect rooms**。在 **Select** 閒置時，若已選一間房，該房會作為保留的第一間，再於平面上點選第二間；若尚未選房，則依次點選兩間。按 **Esc** 可取消點選。第一間房會保留其識別碼、名稱、維護係數、EN 範本、高度及其他官方房間屬性，輪廓改為兩房重疊範圍的單一外輪廓。成功後第二間房會被移除。若兩房不在目前樓層、其中一間缺失、兩次點到同一間房、面積沒有重疊（只沿邊相觸或完全不相接不算交集），或結果會變成空、裂成兩塊或以上互不相連的部分、形成洞、自交、少於 3 個不重複角點、面積小於 0.01 m²，或無法得到單一簡單輪廓，指令會被拒絕，房間不變，並在狀態列說明原因。屬於任一間房、且 XY 仍在交集輪廓內的燈具會改歸保留房間；落在輪廓外的燈具留在該層並取消房間歸屬。燈具不會被刪除。計算結果會留在原位，直到再按 Calculate。一次成功交集可用 **Ctrl+Z** 整步撤銷。此增量不包括對齊。

若要把目前樓層上兩間房的互斥部分留下（第一間 XOR 第二間），可在 Construction tools 按 **XOR rooms**。在 **Select** 閒置時，若已選一間房，該房會作為保留的第一間，再於平面上點選第二間；若尚未選房，則依次點選兩間。按 **Esc** 可取消點選。第一間房會保留其識別碼、名稱、維護係數、EN 範本、高度及其他官方房間屬性，輪廓改為對稱差的單一外輪廓。成功後第二間房會被移除。若兩房不在目前樓層、其中一間缺失、兩次點到同一間房、面積沒有重疊（只沿邊相觸或完全不相接不算 XOR），或結果會變成空、裂成兩塊或以上互不相連的部分（兩房都留下剩餘部分時通常如此）、形成洞（包括一間完全落在另一間內部）、自交、少於 3 個不重複角點、面積小於 0.01 m²，或無法得到單一簡單輪廓，指令會被拒絕，房間不變，並在狀態列說明原因。若第二間房是咬住第一間外輪廓的一角或一邊，結果可以是單一 L 形或帶缺口的輪廓。屬於任一間房、且 XY 仍在 XOR 輪廓內的燈具會改歸保留房間；落在輪廓外的燈具留在該層並取消房間歸屬。燈具不會被刪除。計算結果會留在原位，直到再按 Calculate。一次成功 XOR 可用 **Ctrl+Z** 整步撤銷。此增量不包括對齊。

若要把目前樓層上的房間對齊參考房間，可在 Construction tools 按 **Align rooms**。先選對齊方式（Left、Right、Top、Bottom、H centre 或 V centre；預設為 Left），再於 **Select** 閒置時點選房間：若已選一間房，該房會作為參考（不移動），再於平面上點選要移動的第二間；若尚未選房，則依次點選參考房間與要移動的房間。按 **Esc** 可取消點選。第二間房會平移，使其包圍盒的對應邊或中心與參考房間對齊；形狀不變，參考房間留在原位。兩間房都會保留。屬於被移動房間的燈具會跟隨同一平移，燈具不會被刪除。若兩房不在目前樓層、其中一間缺失、兩次點到同一間房、該房已經對齊（無需移動），或移動後會自交、少於 3 個不重複角點、面積小於 0.01 m²，指令會被拒絕，房間不變，並在狀態列說明原因。計算結果會留在原位，直到再按 Calculate。一次成功對齊可用 **Ctrl+Z** 整步撤銷。此增量不包括均勻分布。

若要在目前樓層上把三間或以上房間沿一軸均勻分布，可在 Construction tools 按 **Distribute rooms**。先選軸向（Horizontal 或 Vertical；預設為 Horizontal），再於 **Select** 閒置時點選至少三間房，然後按 **Enter** 套用。若已選一間房，該房會作為點選集合的第一間。房間按包圍盒的前緣（水平為最小 X，垂直為最小 Y）排序；該順序的第一間與最後一間留在原位，中間的房間會平移，使相鄰包圍盒之間的間隙相等。形狀不變。屬於被移動房間的燈具會跟隨同一平移，燈具不會被刪除。若房間不在目前樓層、其中一間缺失、選取少於三間、房間已經均勻分布，或移動後會自交、少於 3 個不重複角點、面積小於 0.01 m²，指令會被拒絕，房間不變，並在狀態列說明原因。計算結果會留在原位，直到再按 Calculate。一次成功分布可用 **Ctrl+Z** 整步撤銷。按 **Esc** 或再按一次 **Distribute rooms** 可取消點選。

若要在目前樓層上把官方房間的一個角修成圓角，可在 Construction tools 按 **Fillet corner**，並輸入半徑（毫米，或加 `m` / `cm` 後綴；空白數字視為毫米）。在 **Select** 閒置時，若已選一間房，再於平面上點該房的角點控制點即可修圓該角；若尚未選房，則先點選房間，再點角點。邊上的插入控制點不是修圓目標。按 **Esc** 或再按一次 **Fillet corner** 可取消點選。半徑必須大於 0。直線邊可對已有圓弧（先前修圓或 DXF 弧／圓／凸度剖分）的接角再修圓；兩段都是圓弧時亦可。房間仍存成無洞的簡單多邊形，不另存 bulge。該角若已接近直線或已在圓弧剖分上、半徑對相鄰兩邊或圓弧過大、房間不在目前樓層、沒有房間或沒有指定角點，或結果會自交、少於 3 個不重複角點、面積小於 0.01 m²，或無法得到單一簡單輪廓，指令會被拒絕，房間不變，並在狀態列說明原因。屬於該房、且 XY 已不在修圓後輪廓內的燈具會取消房間歸屬；仍在輪廓內的燈具保持歸屬、不會被移動。燈具不會被刪除。計算結果會留在原位，直到再按 Calculate。一次成功修圓可用 **Ctrl+Z** 整步撤銷。若要一次修同一房間的全部尖角，請用 **Fillet all corners**。

若要在目前樓層上把官方房間的全部尖角一次修成圓角，可在 Construction tools 按 **Fillet all corners**，並使用與 **Fillet corner** 相同的半徑欄（毫米，或加 `m` / `cm` 後綴；空白數字視為毫米）。在 **Select** 閒置時，若已選一間目前樓層上的房，按按鈕即立即套用，不必再點角點控制點；若尚未選房，則進入點選模式，在平面上點該層的房間即可套用。邊上的插入控制點不是點選目標。按 **Esc** 或再按一次 **Fillet all corners** 可取消點選。半徑必須大於 0。已接近直線或已修圓的角會被略過，只修剩餘尖角（含直線對弧、弧對弧的接角），並以原來的輪廓一次計算全部圓角；房間仍存成無洞的簡單多邊形。若半徑對相鄰兩邊或圓弧過大（包括同一邊或同一圓弧上兩個圓角的修剪段會重疊）、沒有房間、房間不在目前樓層、沒有可修的尖角（剩餘角都已是直線），或結果會自交、少於 3 個不重複角點、面積小於 0.01 m²，或無法得到單一簡單輪廓，指令會全部拒絕、不套用部分圓角，房間不變，並在狀態列說明原因。屬於該房、且 XY 已不在修圓後輪廓內的燈具會取消房間歸屬；仍在輪廓內的燈具保持歸屬、不會被移動。燈具不會被刪除。計算結果會留在原位，直到再按 Calculate。一次成功的全部圓角可用 **Ctrl+Z** 整步撤銷。

On **Construction**, choose **Draw room** on the **Top** view:

1. Left-click each corner.
2. Type a length (millimetres by default). The next point is locked to a circle of that radius around the last corner; the pointer only sets the direction.
3. Hold **Shift** to constrain to horizontal or vertical.
4. Move the pointer within about 12 CSS pixels of the first corner and click, or press **Enter** when the status shows *click to close*, to close the room. Closing uses the exact start point and does not add an offset vertex. If the pointer is within that start snap, it takes priority over DXF object snap and over ortho or typed-length lock. A draft with fewer than 3 corners cannot close.
5. If a length is typed and locked, one **Backspace** clears that whole length. The next **Backspace** removes the last corner.
6. **Esc** cancels the draft while you are drawing. It does not exit the browser’s fullscreen view. When you are not drawing, **Esc** can still exit fullscreen.

After a room is created, it cannot be dragged as a whole on the plan. With the **Select** tool, select the room and use a corner handle to stretch its shape, or a mid-edge handle to insert a vertex. Use **Select / move** to drag a single fixture on its own. Hold the middle mouse button to pan the view.

With a room selected, drag a corner handle to stretch that existing vertex in world XY; the rest of the polygon stays put. Drag a smaller mid-edge handle to insert a new corner at the closest point on that edge (or on a DXF object snap when one is in range) and place it in the same drag. When a DXF underlay is present, the same official object snap applies to inserts and stretches (endpoint, midpoint, or nearest-on-segment within 8 CSS pixels). If no snap is in range, a new vertex starts on the closest point on the edge, then follows the raw world point. A mid-edge hit uses the same 8 CSS-pixel aperture, excluding a margin around the two endpoints so it cannot steal a corner handle. Dragging inside the room fill no longer moves the whole room. If an insert or stretch would leave fewer than 3 unique corners, a self-crossing outline, or an area below 0.01 m², the polygon is reverted to its pre-insert or pre-drag shape (no stuck extra vertex) and the status bar explains why. With a room selected, hover a corner handle, or click a corner handle without dragging to select that vertex, then press Delete or Backspace to remove it. A mid-edge insert handle is not deletable. Pressing Delete with a room selected but no target vertex does not change the room; the status bar explains that you need a corner handle. If a delete would leave fewer than 3 unique corners, a self-crossing outline, or an area below 0.01 m², the room is left unchanged and the status bar explains why. Draw-room Backspace is unchanged: while a draft is active, one Backspace clears a locked typed length and the next drops the last draft corner.

If the **Building** tree selection is a storey, dragging a room fill still does not translate that storey. A click on a room still selects that room. This is not plan panning: left-dragging an empty area still does not move the view. Hold the middle mouse button to pan.

Set **Room height** in the **Building** panel on the **Construction** tab (millimetres, default 2800) before you create a room. The field stays visible when no room is selected and is used for the next room you draw or create with **Draw room**, **Create rectangle**, or **Create rooms from DXF**. If a room is selected, changing it also updates that room’s ceiling. Other rooms stay as they are.

For a simple rectangle, enter **Length** and **Width** in millimetres (or with an `m` / `cm` suffix). The room is placed at the storey origin `(0, 0)`. Height comes from **Room height**. After creation, use a corner handle to adjust the shape; the room cannot be dragged as a whole to a plan location.

When the current storey’s underlay is a parsed DXF, or a DWG that has been converted to the same linework, **Create rooms from DXF** first builds or updates the storey contour from the outer floor-plate boundary of the full imported drawing, including layers currently hidden by Plan layers (an explicit run of this command replaces a previously auto-built contour; an inner courtyard or other void is not used as the plate), then looks for a room or architectural layout (layers such as WALL, A-WALL, ROOM, PARTITION, FLOOR, LAYOUT, PLAN, 牆, or 房間), not a lighting or ceiling grid (CEILING, GRID, TILE, LIGHT, FIXTURE, and similar). Rooms come from closed polylines, simple closed loops, or wall-network faces on those layout layers, or from room-sized closed shapes that are not a uniform small grid. Hiding walls or architectural layers to view the lighting plan does not stop room detection from using those layers. Auto-created rooms must be at least 1 m² (a typical 600×600 mm ceiling tile is skipped; a small WC can still pass). A large regular grid of similar small rectangles is skipped entirely rather than becoming one room per cell. The hand-drawn **Draw room** minimum remains 0.01 m². Official rooms are simple polygons without holes: if one room lies fully inside another with no connecting wall, only the inner room is kept. CIRCLE, ARC, ELLIPSE, SPLINE (including a spline that has only fit points), old POLYLINE, and LWPOLYLINE bulges are also traced (curves as polygons). A non-mesh 3D POLYLINE is traced in plan (Z is ignored). Paperspace entities (group 67 = 1) are not displayed, snapped, bounded, or used to create rooms. Polygon-mesh and polyface-mesh POLYLINE entities are also traced in plan (Z is ignored). A 3D extrusion (groups 210/220/230) on CIRCLE, ARC, ELLIPSE, LWPOLYLINE, and 2D POLYLINE is applied when tracing in plan. LINE, SPLINE, 3D POLYLINE, and mesh vertices stay in world coordinates; Z is still ignored after the transform. New rooms use the official defaults (maintenance factor 0.80, no EN template inherited from the selected room) and the Building **Room height**. Scale follows the current **Calibrate scale**. Existing rooms are left unchanged. Room detection searches the full imported drawing, including layers currently hidden by Plan layers. If some rooms are found locally, AI may still be used for remaining space inside the contour when Room-analysis AI is enabled; the wait dialog then shows *Analysing rooms…* / *正在辨認房間…*. If no room layout is found, the app also tries AI analysis when a site administrator has enabled Room-analysis AI and saved an API key in **Admin → Settings**. If AI is not configured, the status bar says a site administrator must enable Room-analysis AI in **Admin → Settings** and save an API key; any rooms already found and the contour are kept, and no junk rooms are added. Setting the contour and any new rooms is one undo step.

To merge two rooms on the current storey that overlap or share an edge, use **Union rooms** in Construction tools. With **Select** idle, if a room is already selected it is the first (surviving) room and you then pick the second on the plan; otherwise pick two rooms in order. **Esc** cancels the pick. The first room keeps its id, name, maintenance factor, EN template, height, and other official room properties; the second room is removed after a successful union. The command is refused (status bar, no change) when the rooms are on different storeys, a room is missing, they only touch at a point or not at all, or the union would contain a hole, would cross itself, would have fewer than 3 unique vertices, would have area below 0.01 m², or would not be a single simple room. Fixtures that belonged to the removed room and still lie in the union are reassigned to the surviving room; fixtures that fall outside stay on the storey with their room assignment cleared. Luminaires are not deleted. Calculation results stay in place until you recalculate. **Ctrl+Z** undoes a successful union as one step. Alignment is not included.

To cut one room from another on the current storey, use **Subtract rooms** in Construction tools. With **Select** idle, if a room is already selected it is the first (kept) room and you then pick the cutter on the plan; otherwise pick two rooms in order. **Esc** cancels the pick. The first room keeps its id, name, maintenance factor, EN template, height, and other official room properties; its outline becomes first minus second as a single simple ring. The cutter room stays in place and is not deleted. The command is refused (status bar, no change) when the rooms are on different storeys, a room is missing, the same room is picked twice, the polygons do not overlap in area (edge-touch or disjoint is not a cut), or the result would be empty, would split into two or more disjoint pieces, would contain a hole, would cross itself, would have fewer than 3 unique vertices, would have area below 0.01 m², or would not be a single simple room. Fixtures assigned to the surviving room whose XY no longer lie in the cut outline are unassigned; fixtures of the cutter room are unchanged. Luminaires are not deleted. Calculation results stay in place until you recalculate. **Ctrl+Z** undoes a successful subtract as one step. Alignment is not included.

To keep only the overlapping area of two rooms on the current storey, use **Intersect rooms** in Construction tools. With **Select** idle, if a room is already selected it is the first (kept) room and you then pick the second on the plan; otherwise pick two rooms in order. **Esc** cancels the pick. The first room keeps its id, name, maintenance factor, EN template, height, and other official room properties; its outline becomes the intersection as a single simple ring. The second room is removed after a successful intersect. The command is refused (status bar, no change) when the rooms are on different storeys, a room is missing, the same room is picked twice, the polygons do not overlap in area (edge-touch or disjoint is not an intersection), or the result would be empty, would split into two or more disjoint pieces, would contain a hole, would cross itself, would have fewer than 3 unique vertices, would have area below 0.01 m², or would not be a single simple room. Fixtures of either room that still lie in the intersection are assigned to the surviving room; fixtures that fall outside stay on the storey with their room assignment cleared. Luminaires are not deleted. Calculation results stay in place until you recalculate. **Ctrl+Z** undoes a successful intersect as one step. Alignment is not included.

To keep only the exclusive parts of two rooms on the current storey (first XOR second), use **XOR rooms** in Construction tools. With **Select** idle, if a room is already selected it is the first (kept) room and you then pick the second on the plan; otherwise pick two rooms in order. **Esc** cancels the pick. The first room keeps its id, name, maintenance factor, EN template, height, and other official room properties; its outline becomes the symmetric difference as a single simple ring. The second room is removed after a successful XOR. The command is refused (status bar, no change) when the rooms are on different storeys, a room is missing, the same room is picked twice, the polygons do not overlap in area (edge-touch or disjoint is not an XOR), or the result would be empty, would split into two or more disjoint pieces (typical when both rooms have a remainder), would contain a hole (including a room strictly inside the other), would cross itself, would have fewer than 3 unique vertices, would have area below 0.01 m², or would not be a single simple room. A bite that shares the first room’s outer boundary can succeed as a single ring, such as an L-shape. Fixtures of either room that still lie in the XOR outline are assigned to the surviving room; fixtures that fall outside stay on the storey with their room assignment cleared. Luminaires are not deleted. Calculation results stay in place until you recalculate. **Ctrl+Z** undoes a successful XOR as one step. Alignment is not included.

To align a room to a reference room on the current storey, use **Align rooms** in Construction tools. Choose the alignment first (Left, Right, Top, Bottom, H centre, or V centre; Left is the default). With **Select** idle, if a room is already selected it is the reference (it stays put) and you then pick the room to move on the plan; otherwise pick the reference and the room to move in order. **Esc** cancels the pick. The second room is translated so the matching edge or centre of its bounding box lines up with the reference; its shape does not change, and the reference room stays in place. Both rooms are kept. Fixtures assigned to the moved room follow the same translation. Luminaires are not deleted. The command is refused (status bar, no change) when the rooms are on different storeys, a room is missing, the same room is picked twice, the room is already aligned, or the move would cross itself, would have fewer than 3 unique vertices, or would have area below 0.01 m². Calculation results stay in place until you recalculate. **Ctrl+Z** undoes a successful alignment as one step. Even spacing / distribute is not included.

To space three or more rooms evenly on the current storey, use **Distribute rooms** in Construction tools. Choose the axis first (Horizontal or Vertical; Horizontal is the default). With **Select** idle, click at least three rooms on the plan, then press **Enter** to apply. If a room is already selected it is the first room in the set. Rooms are ordered by the leading edge of the bounding box (min X horizontally, min Y vertically). The first and last rooms in that order stay put; interior rooms are translated so the gaps between consecutive bounding boxes are equal. Shapes do not change. Fixtures assigned to a moved room follow the same translation. Luminaires are not deleted. The command is refused (status bar, no change) when the rooms are on different storeys, a room is missing, fewer than three rooms are selected, the rooms are already evenly spaced, or a move would cross itself, would have fewer than 3 unique vertices, or would have area below 0.01 m². Calculation results stay in place until you recalculate. **Ctrl+Z** undoes a successful distribute as one step. **Esc**, or clicking **Distribute rooms** again, cancels the pick.

To round one corner of an official room on the current storey, use **Fillet corner** in Construction tools and enter the radius in millimetres (or with an `m` / `cm` suffix; a bare number is millimetres). With **Select** idle, if a room is already selected, click a corner handle of that room to fillet that corner; if no room is selected, pick the room first, then the corner. A mid-edge insert handle is not a fillet target. **Esc**, or clicking **Fillet corner** again, cancels the pick. The radius must be greater than 0. A straight wall can be filleted against an existing arc (from a previous fillet or from DXF ARC / CIRCLE / bulge tessellation), and arc–arc junctions are supported the same way. The room is still stored as a simple polygon without holes (no bulge field). The command is refused (status bar, no change) when the corner is already straight or already on a tessellated arc run, the radius is too large for the adjacent edges or arcs, the room is not on the current storey, a room or corner is missing, or the result would cross itself, would have fewer than 3 unique vertices, would have area below 0.01 m², or would not be a single simple room. Fixtures assigned to the room whose XY no longer lie in the filleted outline have their room assignment cleared; fixtures still inside keep their assignment and are not moved. Luminaires are not deleted. Calculation results stay in place until you recalculate. **Ctrl+Z** undoes a successful fillet as one step. To fillet every remaining sharp corner of the same room in one command, use **Fillet all corners**.

To fillet every remaining sharp corner of an official room on the current storey in one command, use **Fillet all corners** in Construction tools and enter the radius in the same field used by **Fillet corner** (millimetres, or with an `m` / `cm` suffix; a bare number is millimetres). With **Select** idle, if a room on the current storey is already selected, clicking the button applies immediately — you do not pick a corner handle. If no room is selected, click a room on the current storey to apply. A mid-edge insert handle is not a target. **Esc**, or clicking **Fillet all corners** again, cancels the pick. The radius must be greater than 0. Already-straight or already-filleted corners are skipped; remaining sharp corners — including line–arc and arc–arc junctions — are filleted in one result polygon, computed against the original outline. The room is still stored as a simple polygon without holes. The command is refused in full, with no partial fillet (status bar, no change), when the radius is too large for the adjacent edges or arcs (including when two fillets would overlap on the same edge or arc), the room is missing, the room is not on the current storey, every remaining corner is already straight (no sharp corner to fillet), or the result would cross itself, would have fewer than 3 unique vertices, would have area below 0.01 m², or would not be a single simple room. Fixtures assigned to the room whose XY no longer lie in the filleted outline have their room assignment cleared; fixtures still inside keep their assignment and are not moved. Luminaires are not deleted. Calculation results stay in place until you recalculate. **Ctrl+Z** undoes a successful fillet-all as one step.

## 樓層輪廓 / Draw storey contour

在 **Construction** 工具列，**Draw room** 旁邊有 **Draw storey contour**，用來描繪目前樓層的樓板輪廓，不必先畫房間。操作與畫房相同：逐點點角、以毫米鎖定長度、**Shift** 正交、回到起點附近封閉、**Backspace** 與 **Esc**。封閉一條有效輪廓會建立或取代該樓層的輪廓，並可整步 Undo / Redo。輪廓不是房間：不會出現在房間列表、燈具表或計算中，也沒有房間屬性。無效輪廓（少於 3 個不重複角點、自交，或面積小於 0.01 m²）會被拒絕。仍可直接畫房間，不必先有輪廓。**Create rooms from DXF** 與匯入後的「從圖則建立」會先用完整匯入圖則（包括目前在圖則圖層中隱藏的建築圖層）的外圍樓板輪廓自動建立樓層輪廓；若你明確按了這些命令，會用這個外輪廓取代先前自動建立的輪廓，而不會把內庭或其他內部空洞當成樓板。若無法從圖則得出有效外輪廓，會在狀態列說明，既有輪廓維持不變，也不會發明幾何。平面 **Top** 會以青綠色虛線顯示該輪廓。**3D** 視圖也會顯示同一輪廓：以樓板與青綠色輪廓／樓層高度帶畫出，即使該層還沒有房間，並把攝影機對準輪廓（以及已有的房間與燈具）。**Front** 與 **Side** 會以青綠色虛線立面範圍顯示該輪廓。輪廓仍然不是房間。

Next to **Draw room** in the **Construction** tools is **Draw storey contour**, to trace the floor-plate outline of the current storey without first drawing rooms. The clicks, typed millimetre length lock, **Shift** ortho, close-to-start, **Backspace**, and **Esc** behaviour match Draw room. Closing a valid path creates or replaces the storey outline as one undo step. The contour is not a room: it does not appear in the room list, luminaire schedule, or calculation, and it has no room properties. Invalid outlines (fewer than 3 unique corners, self-crossing, or area below 0.01 m²) are refused. You can still draw rooms directly. **Create rooms from DXF** and **Create from plan** also set this contour from the outer floor-plate boundary of the full imported drawing, including layers currently hidden by Plan layers. An explicit run of those commands replaces a previously auto-built official contour (so a wrong courtyard outline can be corrected) and does not treat an inner courtyard or other void as the floor plate. If a valid outer boundary cannot be made, the status bar says so, an existing contour is left unchanged, and no geometry is invented. The **Top** plan shows the contour as a teal dashed outline. The **3D** view also shows this contour as a floor plate and a teal outline / storey-height ribbon, even when the storey has no rooms, and fits the camera to the contour (together with any rooms and fixtures). **Front** and **Side** show the contour as a teal dashed elevation span. The contour is still not a room.

## 復原與重做 / Undo and Redo

編輯器頂列有 **Undo** 與 **Redo** 按鈕，可在撤銷後重新套用剛還原的步驟。沒有可撤銷或重做的步驟時，對應按鈕會停用。鍵盤快捷鍵仍然可用：**Ctrl+Z**（Mac 為 **Cmd+Z**）撤銷，**Ctrl+Y** 或 **Ctrl+Shift+Z** 重做；不在文字欄位時，**Ctrl+X** 也可撤銷。唯讀檢視不會顯示這些按鈕。

The editor top bar has **Undo** and **Redo** buttons, so you can redo a step after an undo mistake. Each button is disabled when that action is not available. The keyboard shortcuts still work: **Ctrl+Z** (**Cmd+Z** on a Mac) undoes, and **Ctrl+Y** or **Ctrl+Shift+Z** redoes. **Ctrl+X** also undoes when you are not typing in a field. The buttons are hidden in view-only.

## 樓層標高與層高 / Storey elevation and height

在 **Construction** 分頁，左側 **Building** 在選取樓層後會顯示 **Elevation**（標高，單位公尺）和 **Storey height**（層高，單位公尺）。**Light** 與 **Calculation** 分頁的左側只保留 Building 樹以便選樓層或房間，不會顯示標高、層高或 Room height 編輯欄。

- **Elevation** 是該層樓面的高度。預設地面層（GF）為 0 m。
- **Storey height** 是樓層與樓層之間的間距，預設 3.0 m。按 **Add storey** 時，下一層會放在「本層標高 + 層高」。因此在預設 GF 之上新增的 L1，標高為 3.0 m、層高為 3.0 m。
- **Room height**（預設 2800 mm）是房間內部的天花板高度，與層高分開。3.0 m 與 2.8 m 之間的 0.2 m 差額留給樓板／結構，程式不會自動建出這段。
- 改這些數值只影響目前樓層或所選房間，不會移動其他樓層或既有房間。

On the **Construction** tab, after you select a storey, the **Building** panel shows **Elevation** (metres) and **Storey height** (metres). On **Light** and **Calculation**, the left rail keeps only the Building tree so you can select a storey or room; the elevation, storey height, and Room height editors are not shown there.

- **Elevation** is the floor level of that storey. The default ground floor (GF) is 0 m.
- **Storey height** is the floor-to-floor spacing (default 3.0 m). **Add storey** places the next floor at this storey’s elevation + storey height, so L1 added above the default GF is at elevation 3.0 m with a storey height of 3.0 m.
- **Room height** (default 2800 mm) is the ceiling inside a room, and is separate from storey height. The 0.2 m difference between 3.0 m and 2.8 m is left for the slab / structure; it is not modelled automatically.
- Changing these values does not move other storeys or existing rooms.

若要複製目前樓層，可在 **Construction** 分頁左側 **Building** 按 **Copy storey**。來源樓層及其房間、燈具維持不變。新樓層名稱為 **Copy of {名稱}**；若名稱已存在，則用 **Copy of {名稱} 2**、3，以此類推。新樓層會放在來源樓層正上方，標高為「來源標高 + 來源層高」，因此不會與來源樓板重疊；若該標高已被另一樓層佔用，會再按來源層高往上尋找空位。層高與來源相同。房間會連同平面輪廓、高度、物料反射率、維護係數、EN 目標及其他官方房間屬性一併複製，但使用新的識別碼。來源樓層上的燈具會以相同平面位置、安裝高度、旋轉及光度檔參考複製，並改歸到新房間；未歸屬的燈具在新樓層仍為未歸屬。底圖與計算結果不會被複製，須在新樓層再按 Calculate。成功後會選取新樓層，平面會顯示該層。一次成功複製可用 **Ctrl+Z** 整步撤銷。若目前沒有樓層、來源樓層缺失，或複製結果無效，指令會被拒絕，場景不變，並在狀態列說明原因。

To copy the current storey, use **Copy storey** in the **Building** panel on the **Construction** tab. The source storey, its rooms, and its luminaires stay as they are. The new storey is named **Copy of {name}**, or **Copy of {name} 2**, 3, and so on if that name is already used. It is placed immediately above the source at source elevation + source storey height, so the new floor does not overlap the source slab. If another storey already occupies that elevation, the copy steps up by the source storey height until a free slot is found. The copy keeps the source storey height. Rooms are copied with the same plan polygons, heights, materials, maintenance factor, EN targets, and other official room properties, but with new ids. Luminaires on the source storey are copied with the same plan position, mounting height, rotation, and photometry reference, and reassigned to the new rooms; unassigned luminaires stay unassigned on the copy. Underlays and calculation results are not copied — run **Calculate** on the new storey. After a successful copy, the new storey is selected so the plan shows it. **Ctrl+Z** undoes a successful copy as one step. The command is refused (status bar, no change) when the building has no storey, the current storey is missing, or the copy would not be a valid storey.

## 按圖則燈碼佈燈 / Place from plan codes

在 **Light** 模式，左側 **Detect from plan**／**Import schedule** 附近有 **Place from plan codes**（按圖則燈碼佈燈）。此功能從目前樓層已匯入的 DXF，或已轉換的 DWG 圖則，讀取圖上的燈碼文字（TEXT／MTEXT，以及 INSERT 圖塊展開後的文字），再用專案的 **Code map** 對應到燈具。這是確定的圖則文字讀取，不會猜測未對應的代碼，也不會改動房間。

1. 須先匯入 DXF 或已轉換的 DWG 圖則。若本層沒有此類圖則、圖上沒有文字，或可見圖層上已沒有燈碼，指令會被拒絕，狀態列會說明原因，並且不會寫入燈具。
2. 按 **Scan plan codes** 掃描。較長時間會顯示官方載入對話框（「Scanning plan codes…／正在掃描圖則燈碼…」），頁面保持可回應。隱藏圖層上的燈碼不會列入。位置使用與描線相同的單位與校正比例，座標以公尺顯示。
3. 預覽表列出代碼、對應狀態（已對應／未對應／多項匹配）、位置與所在房間。可逐列接受或拒絕，或按 **Accept all mapped** 接受已對應且在房間內的列。已接受但未對應或多項匹配的列會阻止提交，須先補代碼對應或拒絕該列，系統不會自行猜測。
4. 落在本層任何房間之外的點會略過，並顯示略過數量；不會被強行歸入房間，也不會放在空白處。落在房間內的點會使用該房間。選取燈具不會改動作用中房間。
5. 安裝高度與從圖則偵測或匯入 schedule 相同（房間高度減 0.1 m）。若圖則文字有旋轉角，會套用到燈具朝向；沒有則為 0°。
6. 可選 **Replace prior plan-code fixtures**（預設關閉）只取代本層先前由此功能放置的燈具；用手放置的燈具不會被刪除或移動。可選 **Calc after commit**，提交後計算，計算失敗仍會保留已放置的燈具。
7. 按 **Commit plan codes** 才會寫入燈具。唯讀專案會隱藏此操作。此功能不會取代 **Detect from plan**（圖則影像 OCR）或 **Import schedule**（CSV）。

In **Light** mode, **Place from plan codes** sits near **Detect from plan** and **Import schedule**. It reads lighting-code text already drawn on the imported DXF, or a converted DWG, on the current storey (TEXT / MTEXT, including text exploded from INSERT blocks) and matches each code with the project **Code map**. The operation is a deterministic reading of plan text. It does not guess unmapped codes, and it does not change rooms.

1. Import a DXF or converted DWG plan first. If this storey has no such plan, the plan has no text, or no codes remain on the visible layers, the command is refused with a status-bar reason, and no fixtures are written.
2. Click **Scan plan codes**. If the scan takes time, the official loading dialog shows *Scanning plan codes…* / *正在掃描圖則燈碼…*, and the page stays responsive. Codes on hidden layers are not listed. Positions use the same units and Calibrate scale as the plan linework, and are shown in metres.
3. The preview table lists each code, map status (mapped / unmapped / ambiguous), position, and containing room. Accept or reject rows, or use **Accept all mapped** for mapped rows that fall inside a room. Accepted but unmapped or ambiguous rows block commit until you update the code map or reject those rows — the app does not guess.
4. Points outside every room on the current storey are skipped, and the skipped count is shown. They are not forced into a room and are not placed in empty space. Points inside a room use that room. Selecting a fixture does not change the active room.
5. Mounting height follows the same rule as Detect from plan and Import schedule (room height minus 0.1 m). If the plan text has a rotation, that heading is applied to the fixture; otherwise rotation is 0°.
6. Optional **Replace prior plan-code fixtures** (off by default) replaces only fixtures previously placed by this command on this storey. Fixtures you placed by hand are not deleted or moved. Optional **Calc after commit** runs the calculation after placing; if the calculation fails, the fixtures are still kept.
7. **Commit plan codes** writes the fixtures. The action is hidden on a view-only project. This does not replace **Detect from plan** (raster OCR) or **Import schedule** (CSV).

## 直線排列 / Line array

在 **Light** 模式，先在左側選一個房間，再開右側 **Arrange** 的 **Line**（直線）。

1. 可在 **Top** 平面圖上點兩下，設定線段的起點與終點。第一次點擊是起點，第二次點擊完成線段，預覽會沿這條線更新。
2. 線段完成後，再點一下會開始一條新線（先重設起點，再點終點）。
3. 未完成起點時按 **Esc** 會取消該起點，回到用數量與間距的預設直線。即使瀏覽器處於全畫面，也不會因此退出全畫面。沒有未完成點選時，**Esc** 仍可用來退出全畫面。
4. 若未點選端點，**Count**、**Spacing X** 與 **Rotation** 仍會在房間中心沿旋轉方向排成一直線，行為與先前相同。
5. 點選端點後，燈具由起點到終點均勻分布；沿線間距由線段長度與 **Count** 決定，並顯示在 **Along line** 欄。**Rotation** 仍是燈具朝向，不是線的方向。
6. Spacing Y 在直線模式維持停用。直線排列只沿一條線放置，不會用 Spacing Y 再排第二列。矩形排列才使用 Spacing Y。
7. 落在房間多邊形外的點不會放置；與同房已有燈具相距 1 mm 內的點會略過，既有燈具不會被刪除。點 **Clear line** 可清除已選線段。點選直線時，雙擊空白處不會重置視野，仍可用滾輪縮放。

In **Light** mode, select a room in the building tree, then choose **Line** in **Arrange**.

1. Click two points on the **Top** plan to set the line start and end. The first click is the start; the second click completes the segment and the preview follows that line.
2. After a segment is complete, a later click starts a new line.
3. **Esc** cancels an unfinished start and returns to the centred numeric line. It does not exit the browser’s fullscreen view. When you are not mid-pick, **Esc** can still exit fullscreen.
4. If you do not pick endpoints, **Count**, **Spacing X** and **Rotation** still place a line through the room centre, as before.
5. With endpoints picked, fixtures are spaced evenly from start to end. The along-line spacing comes from the segment length and **Count**, and is shown in **Along line**. **Rotation** is still the fixture orientation, not the line direction.
6. **Spacing Y stays disabled** in Line mode because a line array places fixtures along one line only. **Spacing Y** is used by Rectangular arrays.
7. Points outside the room polygon are not placed. Points within 1 mm of an existing fixture in the same room are skipped; existing fixtures are kept. **Clear line** removes the picked segment. While you are picking a line, double-click does not reset the view; wheel zoom still works toward the cursor.


## 圓形排列 / Circular array

在 **Light** 模式，先在左側選一個房間，再開右側 **Arrange** 的 **Circle**（圓形）。

1. 用 **Count**、**Radius**（公尺）和 **Rotation** 放置燈具。預設圓心是房間外接矩形的中心，與直線模式未點選端點時所用的中心相同。半徑以欄位上看到的數值為準；未改過時，會按房間較短邊的約四分之一預填。
2. 可在 **Top** 平面圖上點一下，設定圓心。之後再點一下會改設圓心。
3. 按 **Esc** 會取消已選圓心，回到房間中心的預設圓。即使瀏覽器處於全畫面，也不會因此退出全畫面。沒有已選圓心時，**Esc** 仍可用來退出全畫面。點 **Clear centre** 同樣回到房間中心。
4. 若未點選圓心，**Count**、**Radius** 與 **Rotation** 仍會以房間中心畫圓。
5. 燈具在圓周上均勻分布。**Count** 為 1 時，單一點放在起始角度的半徑上，而不是圓心。角度 0° 是 +X 方向，**Rotation** 是第一點的起始角度，同時也是燈具朝向，與直線模式相同，不會自動指向圓心或沿切線。
6. Spacing X、Spacing Y 與離牆在圓形模式維持停用。圓形排列只在一個圓周上放置，不會用這些欄位再排第二圈或徑向間距。矩形排列才使用這些欄位。若要依目標照度在房間內自動佈燈，請改用 **Automatic placement**（自動佈燈），那是另一項排列操作，不是圓形排列。
7. 落在房間多邊形外的點不會放置；與同房已有燈具相距 1 mm 內的點會略過，既有燈具不會被刪除。點選圓心時，雙擊空白處不會重置視野，仍可用滾輪縮放。

In **Light** mode, select a room in the building tree, then choose **Circle** in **Arrange**.

1. Place fixtures with **Count**, **Radius** (metres) and **Rotation**. The default centre is the room’s bounding-box centre, the same centre used by the Line numeric fallback. The radius used is the value shown in the field; if you have not changed it, it is prefilled to about a quarter of the room’s shorter side.
2. Click once on the **Top** plan to set the circle centre. A later click replaces the centre.
3. **Esc** cancels an unwanted centre pick and returns to the room-centre fallback. It does not exit the browser’s fullscreen view. When no centre is picked, **Esc** can still exit fullscreen. **Clear centre** also returns to the room centre.
4. If you do not pick a centre, **Count**, **Radius** and **Rotation** still place the circle on the room centre.
5. Fixtures are spaced equally around the circle. When **Count** is 1, the single point is placed at the start angle on the radius, not at the centre. Angle 0° is +X. **Rotation** is the start angle of the first point and is also the fixture orientation, as in Line mode; fixtures are not aimed at the centre or along the tangent.
6. **Spacing X, Spacing Y and wall offset stay disabled** in Circle mode because a circular array places fixtures on one circle only. Those fields are used by Rectangular arrays. To place fixtures automatically from a target illuminance inside the room, use **Automatic placement**, which is a separate Arrange operation, not a circular array.
7. Points outside the room polygon are not placed. Points within 1 mm of an existing fixture in the same room are skipped; existing fixtures are kept. While you are picking a centre, double-click does not reset the view; wheel zoom still works toward the cursor.



## 多邊形排列 / Polygon array

在 **Light** 模式，先在左側選一個房間，再開右側 **Arrange** 的 **Polygon**（多邊形）。

1. 用 **Count** 和 **Rotation** 放置燈具。若未點選自訂路徑，路徑是所選房間的官方封閉輪廓，由第一個角點（Origin）開始，沿周長均勻分布。
2. 可在 **Top** 平面圖上逐點點選自訂路徑，座標使用當前縮放或貼合後的世界座標。路徑完成後，再點一下會開始一條新路徑。
3. 按 **Enter** 或在空白處雙擊，可完成一條開放路徑。在目前縮放下點近第一個頂點（約 4 CSS 像素，與整層拖移的點擊容差同一量級）則閉合路徑。未完成路徑時按 **Esc** 會取消該路徑，回到房間輪廓後備；即使瀏覽器處於全畫面，也不會因此退出全畫面。沒有未完成路徑時，**Esc** 仍可用來退出全畫面。點 **Clear path** 同樣回到房間輪廓後備，也不會退出全畫面。
4. 封閉的自訂路徑（以及未點選時的房間輪廓）沿路徑間距是周長除以 **Count**，因此第一點與最後一點不會重疊在閉合頂點上。**Count** 為 1 時，單一燈具放在第一個角點；自訂路徑則放在第一個點選頂點。開放的自訂路徑由起點到終點均勻分布，**Count** ≥ 2 時包含兩端；**Count** 為 1 時，單一燈具放在起點。
5. **Rotation** 是燈具朝向，與直線和圓形模式相同，不會自動沿切線或指向室內。
6. Spacing X、Spacing Y 與離牆在多邊形模式維持停用。多邊形排列只沿房間輪廓或自訂路徑放置，不會用這些欄位做內縮或再排第二圈。矩形排列才使用這些欄位。若要依目標照度在房間內自動佈燈，請改用 **Automatic placement**（自動佈燈），那是另一項排列操作，不是多邊形排列。
7. 落在房間多邊形外的點不會放置；剛好在房間邊上的點視為有效。自訂路徑的頂點可以在房間內；規劃點若在房間多邊形外仍會丟棄。與同房已有燈具相距 1 mm 內的點會略過，既有燈具不會被刪除。預覽會顯示已佔略過數，並在點選中及設定後顯示自訂路徑。點選自訂路徑進行中，雙擊空白處不會重置視野（會用來完成開放路徑），仍可用滾輪縮放。畫房、校正、直線或圓心點選進行中不會開始多邊形路徑點選；路徑點選進行中，不會開始拖移燈具、房間或樓層。

In **Light** mode, select a room in the building tree, then choose **Polygon** in **Arrange**.

1. Place fixtures with **Count** and **Rotation**. If you do not pick a custom path, the path is the selected room’s official closed outline, starting at the first corner (Origin), with fixtures spaced equally along the perimeter.
2. Click on the **Top** plan to add path vertices in the current zoomed or fitted world coordinates. After a path is finished, a later click starts a new path.
3. **Enter** or a double-click on empty background finishes an open path. Click near the first vertex (within about 4 CSS pixels at the current zoom, the same order as the storey-drag click slop) to close the path. **Esc** cancels an unfinished path and returns to the room-outline fallback. It does not exit the browser’s fullscreen view. When you are not mid-pick, **Esc** can still exit fullscreen. **Clear path** also returns to the room-outline fallback and does not exit fullscreen.
4. A closed custom path, and the room outline when no custom path is set, uses spacing equal to the perimeter divided by **Count**, so the first and last points do not coincide on the closing vertex. When **Count** is 1, the single fixture sits at the first corner, or at the first picked vertex on a custom path. An open custom path spaces fixtures equally from start to end, including the endpoints when **Count** ≥ 2; when **Count** is 1, the single fixture sits at the start.
5. **Rotation** is the fixture orientation, as in Line and Circle modes; fixtures are not aimed along the tangent or inward.
6. **Spacing X, Spacing Y and wall offset stay disabled** in Polygon mode because a polygon array places fixtures on the room outline or a custom path. Those fields are used by Rectangular arrays. There is no inset or second ring. To place fixtures automatically from a target illuminance inside the room, use **Automatic placement**, which is a separate Arrange operation, not a polygon array.
7. Points outside the room polygon are not placed. Points that lie exactly on the room edge are treated as valid. Custom-path vertices may lie inside the room; planned points outside the room polygon are still dropped. Points within 1 mm of an existing fixture in the same room are skipped; existing fixtures are kept. The preview still shows the skipped occupied count, and the custom path is visible while picking and after it is set. While you are mid-pick, double-click does not reset the view (it finishes an open path); wheel zoom still works toward the cursor. Polygon path pick does not start during Draw room, calibrate, or a mid line or circle pick. Fixture hits, room drag, and storey drag do not start while a polygon path is mid-pick.


## 自動佈燈 / Automatic placement

![自動佈燈 / Automatic placement](/docs/guide/automatic-placement.svg)

在 **Light** 模式，先在左側選一個房間，再開右側 **Arrange** 的 **Automatic placement**（自動佈燈）。唯讀專案會隱藏此操作。現有的矩形、直線、圓形與多邊形排列維持不變。

1. 若房間已設定 EN 12464-1 輔助範本，目標維持照度 Ēm 會預填該範本的 Ēm，並顯示其均勻度 Uo 作為參考。可自行改寫 Ēm。未設定範本時，預設目標是 500 lx。這只是設計輔助，不是認證，也不能代替 **Calc**。
2. 數量先按流明法估算：n ≈ ceil((Ēm × A) / (Φ × η × MF))，利用系數 η 預設 0.6（可在 0.5–0.85 調整），維護系數 MF 取自房間設定。若按此數量在房間多邊形內排不下，或隱含間距會超過最大距高比 S/Hm，系統會增加到剛好滿足這三項條件的最小整數。預設最大 S/Hm 為 1.5；若範本 Uo ≥ 0.70，預設收緊為 1.25。可在面板改寫最大 S/Hm。掛燈高度與 Detect from plan、Import schedule、按圖則燈碼相同（房間高度減 0.1 m）；S/Hm 的 Hm 是掛燈面高出工作面的高度。
3. 佈燈跟著實際房間多邊形（包括 L 形或其他凹形簡單多邊形），使用離牆內縮，並在可用範圍內盡量均勻排列。不會先在外接矩形上排網格再把落在房間外的點丟掉，以免 L / T 形房間照度不足。點必須在官方房間多邊形內（邊上也算在內），不會放到房間外的空白處，也不會改動房間。**Rotation** 是燈具朝向，與其他排列工具相同。
4. 先按 **Preview** 在 **Top** 預覽規劃點、盞數、流明法估算的維持 Ēm、間距，以及範本目標參考。規劃較久時，載入對話框會顯示 *Planning automatic placement…* / *正在規劃自動佈燈…*。沒有房間、缺少光通量、目標無效、離牆後沒有可佈範圍，或每個規劃點都已被佔用時，會顯示原因且不會寫入。
5. 與同房已有燈具相距 1 mm 內的點會略過，既有燈具不會被刪除或移動；預覽會顯示已佔略過數。若全部規劃點都已被佔用，會拒絕寫入。套用前若該房已有計算結果，會先出現捨棄結果的確認。可選 **Calc after place / 放置後計算**。套用後狀態會提醒僅供估算，請用 **Calc** 確認最終 Ēm。

In **Light** mode, select a room in the building tree, then choose **Automatic placement** in **Arrange**. The action is hidden on a view-only project. Rectangular, Line, Circle and Polygon arrays are unchanged.

1. If the room has an EN 12464-1 assist template, the maintained target Ēm defaults to that template’s Ēm, and the template’s uniformity Uo is shown as a reference. You may override Ēm. If no template is set, the default target is 500 lx. This is design assist only — not certification — and it is not a substitute for **Calc**.
2. Quantity starts from the lumen method: n ≈ ceil((Ēm × A) / (Φ × η × MF)), with utilance η defaulting to 0.6 (adjustable between 0.5 and 0.85) and the maintenance factor MF from the room settings. The count is then raised if needed so that every required fixture can be placed inside the room polygon and the implied spacing stays within the maximum spacing-to-height ratio S/Hm. The default maximum S/Hm is 1.5; if the template Uo is at least 0.70, the default tightens to 1.25. You can override the maximum S/Hm in the panel. Mounting height is the same as Detect from plan, Import schedule, and Place from plan codes (room height minus 0.1 m). Hm for S/Hm is the mounting height above the workplane.
3. The layout follows the actual room polygon, including L-shaped and other concave official simple polygons, using the wall-offset inset and aiming for even spacing. It does not plan a bounding-box grid and then drop points that fall outside, which would undershoot Ēm in L- or T-shaped rooms. Points must lie inside the official room polygon (the edge counts as inside). Fixtures are not placed in empty space outside the room, and rooms are not changed. **Rotation** is the fixture heading, as in the other array tools.
4. Press **Preview** first to see the planned points on the **Top** view, with the planned count, the lumen-method estimated maintained Ēm, the spacing, and any EN-template target reference. If planning takes time, the official loading dialog shows *Planning automatic placement…* / *正在規劃自動佈燈…*. If there is no room, no luminaire flux, an invalid target, no usable area after the wall offset, or every planned point is occupied, the status explains the reason and nothing is written.
5. Points within 1 mm of an existing fixture in the same room are skipped; existing fixtures are not deleted or moved. The preview shows the skipped count. If every planned point is occupied, the write is refused. If the room already has calculation results, the discard-results confirmation appears before apply. Optional **Calc after place** runs the calculation after placing. After apply, the status reminds you: **Estimate only — run Calc** for the final Ēm.

在 **Top** 視圖，只要目前樓層有房間已有計算結果，不必先選房間，即可在圖面左上角、與視圖及 Fullscreen 按鈕同一組浮動控制中，分別開啟或關閉 **False colour**（偽色）、**Isolines**（等照度線）和 **Value labels**（數值圖）。**Isolines** 與 **Value labels** 是同一種按鈕，可以疊加在偽色上，並在工作面網格上顯示或隱藏等照度線與照度數值。等照度線與數值會畫在該層所有已有結果的房間上。在 **3D** 視圖，**Greyscale**（灰階）和 **False colour** 是一對互斥的顯示方式：灰階會把同一套照度場畫成由暗到亮的灰色，偽色則使用官方連續色階（黑、紫、藍、青、綠、黃、橙、紅、白），預設按 0–2500 lx 的刻度範圍繪製，相鄰顏色之間平滑過渡；兩者共用圖面下方同一條可調的線性照度刻度（兩端範圍、控制點與 **Reset**）。兩端數值欄是整條刻度條的照度範圍（預設 0 與 2500 lx），刻度標籤與官方九段色階都按這個範圍繪製。兩端白色控制點各有一個緊湊的數值欄，顯示該控制點下方顏色所代表的照度錨點，而不是控制點在刻度條上的位置。拖動控制點只改所選顏色／在條上的位置，不會改錨點數值；輸入錨點只改該顏色代表的照度，不會移動控制點；兩者都不會改動兩端範圍。例如範圍為 0–2500 lx，左控制點停在黑色（色表左端）且錨點為 0 lx，右控制點停在官方紅色且錨點為 500 lx 時，0–500 lx 對應由黑到紅：0 lx 為黑，500 lx 為紅，其間按錨點線性對應官方色階。高於 500 lx 的值使用紅色右側、朝白色方向的官方顏色，並把這段色階拉伸到刻度條右端（2500 lx 才到白），不是沿錨點之間的同一斜率繼續延伸（那樣約 571 lx 就會變成白）。低於左端錨點的值，同樣把控制點左側的顏色拉伸到刻度條左端。這不是把整條黑到白色階重新拉伸到 0–500，也不是把控制點數值當成刻度條上該位置的照度。在灰階模式，刻度條改為灰色漸層，標題為 **Greyscale scale**，3D 表面跟隨該刻度；線性色彩轉換後，低端仍保持可見。**Isolines** 與同一個 **Value labels** 開關是同一種按鈕，可以疊加在灰階或偽色上，把同一套等照度線畫在該房工作面高度上，並顯示或隱藏網格數值。工作面（計算平面）的高度跟隨 **Calculation** 分頁右側的 **Workplane (m)**，修改後 3D 平面會立即上下移動，不必先再計算。**Workplane** 開關（預設顯示）用來顯示或隱藏該工作面平面，但不會隱藏房間地板、牆身或燈具，也不會隱藏 **Greyscale**／**False colour** 或已開啟的 **Isolines**／**Value labels**；工作面隱藏時，這些照度顯示改畫在地板上。在 3D 點選燈具時，該燈具的屬性會顯示在 **Light** 分頁右側；在 **Calculation** 分頁仍可看到該房的計算屬性。點選背景、房間、空白處，或環繞旋轉，都不會取消燈具選取；點另一盞燈會改選它，再點已選的那盞可以取消選取。選取燈具不會改動目前房間，也不會因此把房間單獨隔離；按房間隔離 3D 視圖的行為維持不變。偽色、等照度線與數值都來自同一套計算結果與刻度，不會另造一種光度量。3D 牆身假色（或灰階照度）只畫在向內的受光面上，外牆保持灰色。Top 與 3D 的偽色共用同一套連續色階。刻度條本身按兩端範圍顯示官方連續色階；預設 0–2500 lx 時，刻度為 0、500、…、2500。白色控制點停在所選顏色上（例如黑色與官方紅色），各帶一個照度錨點數值欄（例如 0 與 500），該數值不必等於控制點下方的刻度。更改範圍會重繪刻度與色階比例，控制點保持原來的顏色位置與照度錨點，只在顏色位置會超出色表 0–1 時才夾住。灰階使用同一套六個數值（兩端範圍、兩個顏色位置與兩個照度錨點），對應官方灰色漸層。圖面下方的偽色／灰階刻度條只在 **Calculation** 分頁顯示，可在 Top 與 3D **Apply**／**套用** 按鈕；圖面下方刻度條的 **Reset** 旁也會出現同一個 **Apply**／**套用**。此提示只停在圖面視窗內，不會變成全頁對話框，也不會蓋住下方刻度條；即使尚未按套用，仍可繼續調整控制點、控制點數值、兩端範圍或按 **Reset**，並可在提示周圍平移與縮放。CAD、房間與燈具，以及已開啟的等照度線／數值圖仍會保留。按 **Reset** 的工作面／圖例著色，並重繪平面靜態圖與 3D 紋理。重繪期間會顯示載入對話框「Updating scale…／正在更新比例尺…」，並保持到平面與 3D 著色完成為止，灰階刻度也相同。可把目前刻度條上顯示的六個數值（兩端範圍、控制點位置、照度錨點），以及當時是偽色還是灰階，儲存為具名範本。按 **Save as template**／**儲存範本** 後會出現雙語名稱對話框；空白名稱會被拒絕。若名稱已存在，會更新該範本，對話框會先說明這一點。**Templates**／**範本** 用來載入已儲存的範本，**Delete**／**刪除** 可刪除所選範本（若刻度條目前的數值與某個範本相同，即可刪除該範本）。範本保存在工作區，重新載入瀏覽器或開啟同一工作區的其他專案時仍可使用，不會寫入專案檔。**Reset** 只把待套用的刻度條恢復為官方預設（範圍 0–2500 lx、控制點在色表兩端、錨點 0 與 2500），不會刪除範本。載入範本後，刻度條會立即更新為待套用狀態；若與目前已套用的刻度不同，圖面著色仍會隱藏，並顯示同樣的雙語套用提示，必須先按 **Apply**／**套用** 才會重繪 Top／3D，載入對話框「Updating scale…／正在更新比例尺…」同樣會等到著色完成，不會略過。唯讀專案不會顯示儲存、載入或刪除範本。Top 的偽色以每房一張圖像畫在平面上；平移與縮放只移動平面變換，不會在拖曳或縮放途中重繪所有房間的偽色圖，游標移動時也不會重建等照度模型。3D 偽色使用與平面相同的官方假色圖，並以正確的色彩空間顯示，以免顏色偏淺或偏黃。偽色與等照度線會畫到接近房間輪廓，並在房與房之間留下一條很細的分隔，避免視覺上連成一塊；計算網格與報告中的牆邊區域數值（預設為網格間距的一半，約 0.25 m）維持不變。沒有結果的房間不會發明數字：等照度線與數值圖切換會停用，並提示先執行 **Calculate**。**False colour**／**Isolines**／**Value labels** 仍留在圖面視圖開關；**Isoline levels**／**等照度線數值** 改在 **Calculation**／**計算** 分頁右側屬性欄，專案共用、預設收合，點擊標題才展開。預設為 **Auto**／**自動**，仍按結果範圍自動分級；也可改為 **Custom**／**自訂**，自行新增、刪除或輸入以 lx 為單位的等照度線數值（須為大於 0 的有效數字，會自動排序並去掉重複）。空白、無法解析或非正數的列表會被拒絕，並以中英狀態說明，同時保留上次有效設定，不會把無效數值寫入專案。**Presets**／**預設** 提供內建起始預設 100／200／300／500 與 300／500／750，可套用到目前專案；你也可以儲存、重新命名或刪除自己的具名預設。內建預設不會被覆蓋。唯讀專案仍按已儲存的自動或自訂設定顯示等照度線，但會隱藏或停用數值與預設的編輯。Top、3D、Full PDF 既有的 2D 等照度圖，以及 Full PDF 的 **3D Isolines**／**3D 等照度線** 章節，使用同一套數值；圖面下方的偽色／灰階照度刻度條維持不變，不是等照度線列表。確定數值、放開輸入或套用預設後，若需要重繪，會顯示載入對話框「Updating isolines…／正在更新等照度線…」；平移、縮放或在輸入途中逐字更改時，不會重建等照度模型。

匯出 **Full PDF report** 時，會先出現「Exporting PDF report…／正在匯出 PDF 報告…」載入對話框，大型專案可能需要較長時間，但頁面保持可回應，不會卡住瀏覽器分頁。每間已計算房間的摘要會附上工作面等照度線圖，並標上沿線數值與網格數值。即使 3D 視圖未能擷取，這些由平面模型產生的圖仍會匯出。既有的偽色工作面圖與 3D 灰階／偽色章節維持不變，也不會拿掉既有的 2D 等照度線圖。報告另有獨立的 **3D Isolines**／**3D 等照度線** 章節，以與灰階／偽色相同的官方視角，把等照度線與沿線／網格數值畫在工作面上；專案總覽與各房間摘要都會附上，並使用目前的 Isoline levels（自動或自訂，包括預設）。若 3D 視圖未能擷取，全部 3D 靜態圖（包括等照度線圖）會略過，並以狀態列說明，其餘章節（包括 2D 等照度線圖）仍會匯出。若灰階／偽色已成功但某一房間的 3D 等照度線擷取失敗，不會發明該房的圖，已成功的章節會保留。整份報告使用同一套字型（Source Sans 3），相同章節的字級一致。燈具明細表（Luminaire schedule）以表格列出，不是純文字清單。表格儲存格會隨內容加高，較長的型號或其他欄位會完整換行顯示，不會被裁切。工作面偽色圖會把照度場平滑取樣，避免出現計算格線般的方格，並且使用與編輯器相同的連續色階，因此也不會呈現分段色塊。報告中的圖片會壓縮，讓 Full PDF 檔案維持在較小體積。產品頁的平面符號會縮放以放入專用欄位，不會蓋住規格表。匯出 Full PDF、.lxm 或其他檔案時，若瀏覽器支援，會先出現儲存路徑對話框。若專案已開啟只讀分享，封面會印上該專案的連結與 QR 碼，訪客可以瀏覽但不能編輯。

On the **Top** view, when any room on the current storey has calculation results, you do not need to select a room first: use the floating controls at the top left of the plan, next to the view and Fullscreen buttons, to turn **False colour**, **Isolines**, and **Value labels** on or off independently. **Isolines** and **Value labels** use the same button style and can overlay False colour, to show or hide isolines and illuminance values on the workplane grid. Isolines and labels are drawn on every room on that storey that has results. On the **3D** view, **Greyscale** and **False colour** are the only exclusive display modes: Greyscale paints the same official illuminance field from dark to light grey, and False colour uses a continuous official colour scale (black, violet, blue, cyan, green, yellow, orange, red, white) painted across the scale-bar lux range (default 0–2500 lx), with smooth interpolation between adjacent colours. Both modes share the same interactive linear illuminance scale bar under the view (end range, handles, and **Reset**). The end number boxes are the lux range of the whole bar (default 0 and 2500 lx). Tick labels and the official nine-stop palette follow that range. Each white handle has its own compact lux field: that number is the lux the colour under the handle represents (a lux anchor), not the lux at that position on the bar. Dragging a handle changes only the picked colour / place on the bar, and does not change the anchor. Typing a handle lux changes only that colour’s lux anchor, and does not move the handle. Neither action changes the end range. For example, with a 0–2500 lx bar, the left handle on black (the left end of the palette) with lux 0, and the right handle on official red with lux 500, 0–500 lx maps from black to red: 0 lx is black, 500 lx is red, and values in between interpolate between those handle colours. Values above 500 lx use official colours to the right of red (towards white), stretched out to the right end of the bar, so 2500 lx is white and a value such as 788 lx stays reddish — they do not continue along the same slope as 0–500, which would reach white at about 571 lx. Values below the left anchor likewise stretch the colours to the left of that handle down to the left end of the bar. This does not stretch the full black-to-white palette across only 0–500, and the handle number is not the lux at that tick on the bar. In Greyscale the bar uses a grey gradient and the title **Greyscale scale**, and the 3D surfaces follow that scale; the low end stays visible after linear colour conversion. **Isolines** and the same **Value labels** control are matching buttons that can overlay either mode. Isolines are drawn on the workplane at the room’s workplane height, and Value labels show or hide grid values. The displayed 3D workplane (calculation plane) follows **Workplane (m)** in the **Calculation** tab room properties immediately; you do not need to calculate first for the plane to move. A **Workplane** control (shown by default) shows or hides that plane without hiding the room floor, walls, or fixtures, and without hiding **Greyscale** / **False colour** or **Isolines** / **Value labels** when those overlays are on. When the workplane is hidden, Greyscale, False colour, Isolines, and Value labels stay visible, drawn on the floor. Selecting a fixture in 3D shows that fixture’s properties on the **Light** tab right rail; calculation properties for the room stay visible on the **Calculation** tab. Clicks on the background, a room, empty space, or orbiting do not deselect it. Clicking another fixture selects it; clicking the already-selected fixture may toggle the selection off. Selecting a fixture does not change the active room and does not isolate a room. 3D isolate-on-select for a chosen room is unchanged. False colour, isolines, and the labels all come from the same calculation results and scale; they do not invent a third photometric quantity. 3D wall false colour (or greyscale illuminance) is drawn only on the inward illuminated face, and the outside of the wall stays grey. Top and 3D false colour share the same official continuous colour scale. The bar itself paints the official continuous palette across the end range; on the default 0–2500 lx bar, ticks are 0, 500, …, 2500. The white handles sit on the chosen colours (for example on black and on official red), each with a lux-anchor field (for example 0 and 500) that need not match the tick under the handle; the end boxes show the overall range (for example 0 and 2500). Changing the end range rescales the bar and ticks. Handles keep their colours (the same relative t on the bar) and their lux anchors, and are only clamped if t would leave 0–1. Greyscale uses the same six-number model on the official grey ramp. The false-colour / greyscale scale bar under the view appears only on the **Calculation** tab, where it is available in both Top and 3D. Display toggles stay available on every tab, and overlays you already turned on remain visible; only the scale bar is hidden off Calculation. While you drag a handle, type a lux anchor, or change the end range, the bar updates immediately (the range rescales the ticks and palette; dragging changes only the colour position, and typing changes only the anchor), but the whole false-colour or greyscale illustration on the plan and in 3D is taken off so the old colouring is not left on screen. When the pending bar range, colour-handle positions, or lux anchors differ from the scale the view is currently showing, a larger prompt appears on the plan (or 3D) viewport: *Apply to change false colour* / *套用以更改偽色* (or *Apply to change greyscale* / *套用以更改灰階* in greyscale), with an **Apply** / **套用** button. The same **Apply** / **套用** control also appears on the scale bar, next to **Reset**. The prompt stands only on the viewport: it is not a full-page or app-wide modal, and it does not cover or block the scale bar. You can keep adjusting the handles, the handle numbers, the end range, or press **Reset** before you apply, and you can still pan and zoom around the prompt. CAD, rooms, fixtures, and isolines or value labels that are already on stay visible. **Reset** returns the pending state to a 0–2500 lx bar range, handles at the ends of the official chart (black and white), and lux anchors 0 and 2500. If that differs from the scale already applied to the plan, the prompt stays and the colour field remains hidden; if it matches the applied scale, the prompt disappears and the applied illustration is shown again. Only **Apply** / **套用** (from the prompt or the bar) commits the pending bar range, colour-handle positions, and lux anchors to Top, 3D, and later Full PDF workplane / legend colouring, and rebuilds the static plan bitmap and 3D textures. A loading dialog shows *Updating scale…* / *正在更新比例尺…* during that rebuild, and it stays until the plan and 3D have finished recolouring, including when the greyscale scale bar is applied. On the Top view, false colour is a per-room image on the plan, and pan and zoom move a live plan transform instead of re-rasterizing every room or rebuilding isolux models during the gesture. Moving the cursor also does not redraw the false-colour field or rebuild isolux models; the DXF snap marker updates on its own layer, and snap stays inactive on idle hover. 3D false colour uses the same official field bitmap as the plan, in the correct colour space, so it does not look washed or yellowed. False colour and isolines are painted close to the room outline, leaving a thin visible gap between adjacent rooms so they do not merge. The calculation grid and the wall-zone value in the report (half the grid spacing, 0.25 m by default) are unchanged. Rooms without results do not invent numbers: the isoline and value-label controls are disabled and ask you to run **Calculate** first. **False colour**, **Isolines**, and **Value labels** stay on the view overlays. **Isoline levels** / **等照度線數值** lives under the **Calculation** tab in the right Properties column (project-wide, collapsed until you click to expand). It defaults to **Auto** / **自動**, which still steps levels from the result range. **Custom** / **自訂** lets you add, remove, or type illuminance levels in lux (finite values greater than 0, sorted and de-duplicated). Empty, unparsable, or non-positive lists are refused with a bilingual status message; the last valid settings are kept and nothing invalid is written to the project. **Presets** / **預設** include the built-in starters 100 / 200 / 300 / 500 and 300 / 500 / 750, which you can apply, and you can save, rename, or delete your own named presets on the project. Built-in starters are not overwritten. In a view-only project, isolines still follow the saved Auto or Custom settings, but editing levels or presets is hidden or disabled. Top, 3D, the existing Full PDF 2D isolux figures, and the Full PDF **3D Isolines** / **3D 等照度線** chapter use the same levels. The false-colour / greyscale illuminance scale bar under the view is unchanged; it is not the isoline level list. After a committed change (pointer up, field commit, or applying a preset), a loading dialog may show *Updating isolines…* / *正在更新等照度線…*. Pan, zoom, and mid-edit typing do not rebuild isolux models.

When you export the **Full PDF report**, the loading dialog shows *Exporting PDF report…* / *正在匯出 PDF 報告…*. A large project can take a while, but the page stays responsive and the browser tab should not freeze. Each calculated room’s Summary includes a working-plane isolux diagram with isolines, contour labels, and value labels. These 2D figures are still exported if 3D views cannot be captured. Existing false-colour workplane figures and 3D greyscale / false-colour chapters are unchanged, and the existing 2D isolux snapshots are kept. The report adds a separate **3D Isolines** / **3D 等照度線** chapter with project-wide and per-room stills from the same official viewpoints as the greyscale / false-colour pair, with isolines and contour / value labels drawn on the workplane using the current Isoline levels setting (Auto or Custom, including presets). If 3D views cannot be captured, those 3D stills (including isolines) are omitted and the status bar explains this; the rest of the report, including 2D isolux figures, still exports. If greyscale / false-colour capture succeeds but a room’s isoline still cannot be captured, that room’s isoline image is omitted and is not invented. The report uses one typeface (Source Sans 3) throughout, with the same font size for the same kind of section. The luminaire schedule is a table, not a plain-text list. Table cells grow in height to fit wrapped content, so a long article number or other field is shown in full and is not clipped. Working-plane false-colour figures sample the illuminance field smoothly, so they do not look like blocky calculation cells, and they use the same continuous colour scale as the editor, so the palette is not posterized either. Report images are compressed so the Full PDF file stays small. The plan symbol on a product sheet is scaled to fit its own column and does not overlap the specification table. Exporting the Full PDF, a .lxm file, or other output files opens a save-path dialog when the browser supports it. When a view-only link is on for the project, the cover includes that link and a QR code. Visitors can browse the project but cannot edit it.

## 計算樓層 / Calc storey

功能列的 **Calc room**、**Calc storey**、**Calc all** 是同一組官方計算按鈕；唯讀專案會隱藏整組，與其他編輯操作一致。

1. 在左側建築樹選好目前樓層（可不必選房間）。
2. 按 **Calc storey**（計算樓層）。狀態列會顯示「Calculating storey…／正在計算樓層…」，並使用與 **Calc room**／**Calc all** 相同的載入對話框「Calculating…／正在計算…」。
3. 只計算**目前樓層**上的每一個房間。其他樓層的既有結果會保留，不會被清掉或覆寫。
4. 缺配光的房間會像 **Calc all** 一樣略過並在狀態說明（可顯示燈具名稱），仍寫入本層可計算房間的結果。沒有燈具的房間同樣略過。
5. 若目前樓層沒有房間，或本層沒有任何可計算房間，會以雙語狀態拒絕，且不寫入新結果。
6. 計算成功後，若選的是樓層而不是單一房間，底部結果列會用既有的樓層加總（`aggregateStoreyResults`）顯示本層合計數字。
7. **Calc room** 仍只算目前房間；**Calc all** 仍算專案內全部房間。本操作不會新增「目前視圖」計算範圍。

![計算樓層 / Calc storey](/docs/guide/calc-storey.svg)

**Calc room**, **Calc storey**, and **Calc all** share the same official Calc control group on the file bar. The whole group is hidden on a view-only project, the same as other edit actions.

1. Select the active storey in the building tree (a room selection is not required).
2. Click **Calc storey**. The status shows *Calculating storey…* / *正在計算樓層…*, and the same loading dialog used by **Calc room** / **Calc all** appears (*Calculating…* / *正在計算…*).
3. Every room on the **active storey** is calculated. Existing results on other storeys are kept and are not cleared or overwritten.
4. Rooms with missing photometry are skipped the same way as **Calc all**, with an explanation in the status (by luminaire name when that is the existing pattern), while results are still written for rooms on this storey that can be calculated. Rooms with no fixtures are also skipped.
5. If the active storey has no rooms, or nothing left that can be calculated, the command refuses with a clear bilingual status and writes nothing new.
6. After a successful storey calc, when the storey (not a single room) is selected, the bottom results strip shows this storey’s combined figures through the existing storey aggregator.
7. **Calc room** still calculates only the active room; **Calc all** still calculates every room in the project. This increment does not add a “current view” calc scope.

## 變更燈具與計算結果 / Changing fixtures and calculation results

若房間已有計算結果，移動、旋轉、編輯位置、刪除、新放燈具，或套用排列、RCP／燈具表／按圖則燈碼提交時，會先出現確認對話框，說明變更燈具會捨棄受影響房間的目前計算結果（偽彩、等照度線、數值圖與結果列都會清除）。按 **Confirm** 後才套用變更並捨棄那些結果；按 **Cancel**、Esc 或點背景則不會變更燈具，亦保留原有結果。若該房沒有計算結果，不會出現對話框，變更會直接套用。拖移燈具時，只在開始拖移前詢問一次；確認後結果已清除，同一手勢其後的移動不會再詢問。

If a room has calculation results, moving, rotating, editing the position, removing, or placing a fixture, or applying an array, RCP, schedule, or plan-code commit, first shows a confirmation dialog: changing lighting fixtures will discard the current calculation results for the affected room(s), including false colour, isolines, value labels, and the results strip. **Confirm** applies the change and discards those results. **Cancel**, Esc, or clicking the backdrop leaves the fixture and the results unchanged. If there are no results, the change is applied immediately and the dialog is not shown. When dragging a fixture, you are asked once at the start of the drag; after you confirm, the results are already cleared, so later moves in that gesture do not re-prompt.


## 3D 發射方向與光束錐 / Emission direction and light cone in 3D

在 **3D** 視圖選取一盞燈具時，會從發光開口沿光學軸（本地向下，即 −Y）顯示發射方向箭頭，以及按光度檔 50%（半峰值／FWHM）光束角張開的半透明光束錐。錐長延伸到該燈所屬房間的工作面；若尚未歸屬房間，則延伸到該樓層地面。細長或明顯不對稱的開口，會依 C0／C90 光束角畫成橢圓錐，而不是錯誤的圓錐。未選取的燈具不顯示箭頭或光錐。箭頭與光錐不會擋住點選。平面 **Top** 上選取時的 C0 旋轉箭頭維持不變。燈具沒有俯仰／瞄準欄位，不會發明傾角。若無法從光度資料量得光束角，會使用保守的預設半角 30°（全角 60°），仍會顯示光錐。

When a fixture is selected in the **3D** view, an emission-direction arrow is drawn from the luminous aperture along the photometric optical axis (local −Y, straight down). A translucent light cone opens at the fixture’s 50% (half-peak / FWHM) beam angle from the photometry table, long enough to reach that fixture’s room workplane, or the storey floor if the fixture has no room. For a clearly elongated opening, the cone uses the C0 / C90 pair rather than a single circular angle. Unselected fixtures have no arrow or cone. The arrow and cone do not catch pointer hits. The Top-view C0 rotation arrow is unchanged. Fixtures have no tilt or aim field; no tilt is invented. If the beam angle cannot be measured from photometry, a conservative 30° half-angle (60° full beam) is used so the cone is still shown.

選取燈具時，右側 **Properties** 的 **Light cone / 光束錐** 也會顯示同一光束角的側視光錐預覽（發射軸與光束錐），不會取代 3D 光錐，也不會改動 X／Y／Z／Rotation 或平面 C0 旋轉提示。軸對稱、只向下發光的光度資料，工作面照度峰值會落在該燈的平面位置正下方；在平面旋轉燈具不會把峰值沿 C0 箭頭方向平移。

When a fixture is selected, **Properties** also shows a **Light cone / 光束錐** side-elevation preview of the same emission axis and beam cone. It does not replace the 3D cone, and it keeps the X / Y / Z / Rotation fields and the Top-view C0 hint. For axially symmetric downward photometry, the workplane illuminance peak stays under the fixture’s plan position; rotating the fixture in plan does not slide that peak along the C0 arrow.

## 房間屬性 / Room properties

選取房間後，屬性會依工作分頁分開顯示。

在 **Construction**，右側只在已選房間且未選燈具時顯示建模屬性：

- 名稱、**Height (mm)** — 房間高度
- **Area** — 房間面積
- **Origin (first corner)** — 第一個角點的位置
- **Bounding min** — 只在第一個角點不是外接矩形的最小角時顯示
- ρ 地板／天花／牆面

工作面、網格間距與維護係數不在此分頁。若未選房間（或已選燈具），Construction 的右欄會收起。

在 **Calculation**，右側顯示計算屬性：房間名稱與面積（供對照）、**Workplane (m)** 與 **Show**、**Grid spacing**、維護係數／CIE 97，以及 EN 12464-1 assist。未選房間時仍會顯示 Isoline levels。選取燈具時，燈具屬性改在 **Light** 分頁右側顯示；選取燈具不會改動目前房間。

After you select a room, properties are split by workflow tab.

On **Construction**, the right-hand rail shows modelling properties only when a room is selected and no fixture is selected: name, **Height (mm)**, **Area**, **Origin (first corner)**, **Bounding min** when the first corner is not the bounding-box minimum, and ρ floor / ceiling / walls. Workplane, grid spacing, and maintenance factor are not shown here. If no room is selected (or a fixture is selected), the Construction right rail hides.

On **Calculation**, the right-hand rail shows calculation properties: room name and area for context, **Workplane (m)** with the **Show** checkbox, **Grid spacing**, maintenance factor / CIE 97, and EN 12464-1 assist. Isoline levels stay visible when no room is selected. When a fixture is selected, its properties appear on the **Light** tab. Selecting a fixture does not change the active room.

## 專案燈具庫 / Fixture library

在 **Light** 模式，右側屬性欄的 **Fixture library** 列出本專案已加入的 IES／LDT／GLDF 燈具，可拖到圖上佈置。此燈具庫只在 Light 分頁出現，不在 Construction。底部的 **Fixtures in project** 表也只在 Light 分頁顯示。可編輯時，**Add from org library** 下拉可從組織燈具庫加入；其下方有兩個按鈕：**Upload IES / LDT / GLDF**（只加入專案列表，不會自動放到圖上）與 **Generate LDT**。按 **Generate LDT** 會彈出對話框，內含原本那些產生參數（流明必填等）；產生成功後會加入專案燈具列表（尚未佈到圖上）並關閉對話框。等候產生時仍會顯示官方載入對話框，並蓋在參數對話框之上。右側屬性欄在靜止狀態不會展開整份 Generate LDT 表單。唯讀專案會隱藏上傳、Generate LDT 與 Add from org library。**Luminaire library** 頁左側的 Generate LDT 表單維持不變，仍直接顯示在列表下方。

In **Light** mode, the right-hand **Fixture library** lists the project's IES / LDT / GLDF luminaires so you can drag them onto the plan. The library is on the Light tab only, not on Construction. The **Fixtures in project** table at the bottom is also Light-only. When editing, **Add from org library** adds an organisation-library item; directly under that select are two buttons: **Upload IES / LDT / GLDF** (adds to the project list only — not placed) and **Generate LDT**. **Generate LDT** opens a dialog with the same generation parameters as before (lumen required, and the rest). After a successful generate, the luminaire is added to the project fixture list (not placed) and the dialog closes. The official wait dialog still appears while generating and sits above the parameter dialog. At rest, the right property panel does not show the full Generate LDT form. View-only hides upload, Generate LDT, and Add from org library. The **Luminaire library** page still keeps its inline **Generate LDT** form below the luminaire list; that page is unchanged.

## 燈具庫 / Luminaire library

在 **Luminaire library** 頁，左側上方是燈具列表（名稱、格式、lm / W、刪除）。左側下方仍是整份 **Generate LDT** 表單（不是編輯器右側的按鈕與對話框），用來產生庫內錐形配光，用法不變。右側極座標預覽區同時是匯入區：可把一個或多個 IES、LDT 或 GLDF（`.gldf`，Global Lighting Data Format）檔拖放到該區，或按該區上的 **Import** 選擇檔案。選取或放下檔案後，會先出現顯示名稱對話框：單檔時可選填一個 **Display name**（並顯示檔名）；多檔時每個 IES、LDT 或 GLDF 各有一列顯示檔名與 **Display name**。名稱可留空，系統會依產品名稱、光度檔說明、型號或檔名決定顯示名稱。按對話框的 **Import** 開始上傳；按 **Cancel**、Esc 或點背景則取消，不會上傳。上傳期間會顯示既有的等候對話框。一次可匯入多個檔案；若其中一個失敗，已成功的檔案會保留，並顯示失敗檔名與原因，其餘檔案會繼續匯入。匯入後列表會重新載入，並在右側開啟最後一個成功匯入的燈具預覽。選取燈具後，可用 **Download .ldt** 下載光度檔，或用 **Download .gldf** 匯出含 product.xml 與內嵌光度檔的 GLDF 容器；既有的 IES／LDT 燈具也可匯出為 `.gldf`。GLDF 若有多個含光度的變體，會各建一筆燈具。沒有內嵌 IES 或 LDT 光度檔的 GLDF 無法匯入。

On the **Luminaire library** page, the luminaire list (Name, Format, lm / W, Delete) is at the top of the left column. **Generate LDT** stays as the full inline form below the list (not the editor's button-and-dialog layout) and is unchanged. The right-hand polar-curve preview is also the import area: drop one or more IES, LDT, or GLDF (`.gldf`, Global Lighting Data Format) files onto that panel, or use the **Import** button on the same section to choose files. After you drop or choose files, a display-name dialog opens first. For one file, you can optionally enter a **Display name** (the filename is shown). For more than one file, each IES, LDT, or GLDF has its own **Display name** field, with the filename visible on that row. Names may be left empty; the display name then follows the product name, photometry description, catalog number, or filename. **Import** on the dialog starts the upload. **Cancel**, Esc, or clicking the backdrop discards the pending files and does not upload. While files are uploading, the existing wait dialog is shown. You can import more than one file at a time. If one file in a batch fails, already-imported files are kept, the failed file and reason are shown, and the rest of the batch still continues. After a fully or partly successful import, the list reloads and the last successfully imported luminaire opens in the preview. With a luminaire selected, use **Download .ldt** for the photometry file, or **Download .gldf** for a GLDF container with product.xml and the embedded photometry. Existing IES or LDT library items can also be exported as `.gldf`. If a GLDF has more than one variant with photometry, each becomes its own library item. A GLDF with no embedded IES or LDT photometry cannot be imported.

其他功能（計算、報告匯出等）可先使用編輯器工具旁的「？」提示。本手冊會隨新操作繼續補上。

Other tools, calculation, and exports are described by the **?** tips next to those controls. This guide will be extended as further operations are documented.
